# komapedit 使用者手冊

本手冊介紹 komapedit 的介面、預覽和編輯操作，並提供匯出 CSV 資料的格式說明。

專案簡介、支援的 BVE 地圖語法及安裝與啟動說明，請參閱[繁體中文 README](README_zhtr.md)。

## 報告問題

komapedit 是一個*80% 以上的內容為 vibeslop*的個人專案，穩定性仍與大型商業軟體有差距。

如果你遇到當機、介面顯示異常、地圖元素特性與 BVE 中不一致、編輯或儲存失敗等問題，可透過 `說明 -> 報告問題` 開啟問題提交頁面，也可以直接存取專案的 [GitHub Issues](https://github.com/NewSapporoNingyo/komapedit/issues)。

提交前請先搜尋是否已有相同問題；若已有報告，可在其中補充資訊。新問題請登入 GitHub 後建立 issue，標題簡要說明出問題的功能和現象，例如「開啟某地圖後，載入 3D 場景預覽時當機」。

**GitHub Issues 僅受理程式異常回報；操作詢問與功能建議不在受理範圍內。**

### 需要提供的資訊

- **作業系統與硬體**：Windows 版本、內部版本號及系統架構。可透過 `Win+R` 輸入 `winver` 檢視 Windows 版本與內部版本號。涉及 3D 顯示或效能問題時，請補充 CPU、記憶體容量、顯示卡型號及顯示卡驅動版本。
- **程式版本**：使用的 komapedit 釋出版本或 Git 提交號，以及程式來源；如果使用自行編譯的版本，請補充 Debug/Release 建置類型和編譯器版本。無法確定版本時，請註明下載或建置日期。
- **問題現象與預期結果**：分別說明希望程式怎樣工作、實際發生了什麼，並保留錯誤提示的完整文字。若涉及卡頓，請說明發生在哪個操作階段及大致持續時間。
- **重現步驟**：從啟動程式、開啟檔案開始，按順序列出操作，寫明相關選單、參數、設定，以及是否點選了「套用」或「儲存」。註明問題是每次必現還是偶發；若僅在特定位置或元素上發生，請提供里程、元素 key 或原始檔位置。
- **主控台記錄**：提供從載入相關檔案到問題發生後的完整記錄，取得方法見下文。記錄較長時可儲存為 `.txt` 附件。
- **重現檔案**：如果問題只在特定地圖上出現，請儘量提供能重現問題的地圖檔案。<br>
若問題發生在不公開的地圖上，請儘量提供能重現問題的最小檔案集，不一定需要提供完整地圖。可透過郵件向開發者傳送必要的檔案（地圖、Include 子地圖、資源清單、模型或貼圖等），並保留相對目錄關係。<br>
若地圖是公開的 BVE 地圖，請提供此地圖的下載連結，以方便專案開發者重現問題。<br>
編輯或儲存問題如有修改前後的檔案，也請一併提供並註明差異。
- **截圖或螢幕錄影**：涉及介面、2D/3D 顯示或操作順序的問題，請附上能展示現象的截圖或短螢幕錄影；同時保留文字說明和記錄，便於搜尋和分析。

上傳前請檢查記錄、截圖和附件中的個人路徑等資訊；若直接在 GitHub Issues 中提供全部資訊，重現檔案應使用可公開分享的內容，並儘量保留觸發問題所需的條件。

### 取得主控台記錄

1. 從 `輔助資訊 -> 主控台視窗` 開啟主控台。
2. 在可重現的情況下，使用測試檔案或檔案副本重複觸發問題，保留檔案載入到問題發生後的記錄；複製前不要點選「清除」。
3. 點選主控台的「複製」，將全部記錄複製到剪貼簿。
4. 將記錄貼上到 Issue 的程式碼區塊中，或儲存為 UTF-8 文字檔案後作為附件上傳。

若程式已經當機、無回應或無法啟動，導致無法複製主控台記錄，請在報告中註明，並提供最後一次操作、錯誤對話方塊或截圖。若能取得 Windows 事件檢視器中的相關應用程式錯誤，也可一併附上。

## 使用方法

本節介紹介面、預覽和編輯操作。檢視地圖可直接使用各類檢視；修改檔案前，請閱讀第 10 節並備份地圖。

### 1. 主介面

主介面由以下部分組成：

- **頂端選單**：開啟檔案、切換視窗、調整 2D/3D 設定以及開啟說明頁面。
- **工具列**：提供開啟、重新載入、編輯、儲存、車站跳轉和里程跳轉等常用操作。
- **中央工作區**：顯示 2D 檢視、檔案結構圖、文字預覽、3D 模型預覽和 3D 場景預覽。多個視窗可以作為分頁疊放，也可以拖曳到其他位置停駐。
- **地圖資訊表格**：通常停駐在右側，用於檢視車站、佈景、號誌、音效和其他地圖元素。
- **主控台視窗**：通常位於右下方，顯示地圖載入、模型載入、編輯和儲存過程中的詳細資訊。
- **底部狀態列**：顯示目前操作狀態以及錯誤、警告數量。

視窗關閉後，可從 `地圖資訊清單`、`2D檢視`、`3D檢視` 或 `輔助資訊` 選單重新開啟。視窗顯示狀態和停駐配置自動儲存。

### 2. 頂端選單

#### 檔案

- `新增...`：開啟「新增檔案精靈」。可新增地圖、Scenario 或資源清單檔案，詳細說明見第 10 節。
- `開啟...`：選擇 `.txt` 或 `.csv` 地圖/Scenario 檔案。也可使用工具列中的「開啟」。
- `最近開啟的地圖`：重新開啟最近使用的地圖，或清除歷史記錄。
- `重新載入`：重新讀取目前地圖、重新整理已啟動的 3D 場景，並重新載入目前單模型預覽。快速鍵為 `F5`。存在未儲存更改時，程式會先要求確認。
- `匯出 CSV...`：選擇目錄，匯出目前自軌道和各條其他軌道的幾何資料，並覆蓋目錄中的同名檔案。不同軌道產生相同輸出檔名時停止匯出，詳情可在主控台檢視。CSV 欄位說明見後文附錄。
- `離開`：關閉程式。存在未儲存更改時，可選擇儲存、放棄或取消離開。

開啟 `BveTs Scenario 2.00` 格式的檔案後，可檢視 Scenario 內容並載入其中的地圖：

- 從 `地圖資訊清單` 的「其他」分組開啟 `Scenario 檔案`，檢視欄位、Route/Vehicle 路徑和權重。啟用編輯模式後，直接在輸入框中修改；標題、作者、說明等文字欄位及 Image 路徑也可補填。
- 右鍵路徑可選擇檔案或開啟目錄。已有 Route/Vehicle 欄位支援新增、刪除和上下移動候選，每個欄位至少保留一個候選。新增候選預設權重為 `1`，需填寫路徑；權重須大於 `0`。
- 只有一個有效 Route 時直接載入該地圖；有多個候選時由使用者選擇。
- Route 缺失、無效或取消選擇時，仍可檢視和編輯 Scenario。Vehicle 在此顯示引用路徑和權重。
- Scenario 修改透過工具列「儲存」或 `Ctrl+Shift+S` 直接寫入檔案。地圖和 Scenario 同時有修改時先儲存地圖；若 Route 候選路徑或順序也已改變，程式會提示再次儲存 Scenario。儲存後使用「重新載入」載入所選地圖。
- 最近檔案、背景對齊歷史和重新載入均以 Scenario 檔案為入口。重新載入時會重新讀取 Scenario、視需要選擇 Route 並重新整理模型；「重新載入線形」會盡量保留場景模型和攝影機。

#### 選項

- `使用者介面設定...`：調整文字大小、介面元件大小和主題色。
- `2D畫布設定 -> 畫布元素尺寸`：調整標記大小、自軌道/其他軌道線寬、圖表標線和網格線寬。
- `2D畫布設定 -> 繪圖範圍...`：輸入最小、最大里程並點選「套用」，調整 2D 顯示範圍。「重設」填回預設範圍，再點選「套用」生效。
- `2D畫布設定 -> 控制點間隔...`：調整軌道幾何的取樣範圍和間隔，點選「套用」重新產生幾何資料。較小間隔可增加曲線取樣密度；CSV 匯出使用重新產生的資料。
- `3D畫布設定`：調整場景繪製距離、編輯元件尺寸、攝影機速度、霧效果、地圖繪製距離、自動載入和效能警告。

文字、元件尺寸、配色和 3D 顯示參數支援即時預覽；點選「確定」儲存設定，「取消」恢復開啟對話方塊前的值。

#### 地圖資訊清單

按車站、佈景、軌道幾何、號誌、音效、效果和其他內容分組開啟各類表格。表格的具體功能見第 6 節。

#### 2D檢視

- 顯示或隱藏整個 2D 檢視視窗、縱斷面圖和曲線半徑圖。
- 顯示或隱藏坡度變化點、坡度值和縱斷面中的其他軌道。
- 匯入、顯示、調整背景圖，或使用兩個車站位置對齊背景圖。調整項包括位置、尺寸、旋轉角度和亮度。

#### 3D檢視

- `佈景模型預覽`：顯示或隱藏單個模型的預覽視窗。
- `3D場景預覽`：顯示或隱藏整張地圖的場景預覽視窗。

#### 輔助資訊

- 分組控制 2D/3D 中的車站、軌道幾何、號誌、音效和效果標記。
- 「軌距設定點」「外軌超高中心設定點」「緩和曲線參數設定點」分別顯示 `CG`、`CC`、`CF` 標記；「閉塞標記」顯示綠色 `S` 標記及號誌索引。這四項預設關閉，可視需要開啟。
- 「先行列車通過點」顯示 `PreTrain.Pass` 標記，啟用編輯模式後可右鍵修改里程、通過時間或刪除。
- 「自軌道標記」和「平面圖上顯示目前位置」控制 3D 場景與 2D 平面圖之間的輔助顯示。
- `其他 -> 自訂訊息`、`檔案結構圖`、`文字預覽`、`主控台視窗` 用於開啟對應工具視窗。

平面圖中的號誌機標記由「地圖號誌」表格的「顯示」核取方塊控制。其他列車路徑在「其他列車」表格中逐項控制。

#### 語言與說明

- `語言`：在 `中文` 子選單中選擇 `简体`、`台湾繁體` 或 `香港繁體`；`English` 和 `日本語` 與 `中文` 子選單並列。目前語言的選項會顯示勾選標記，選擇會儲存並在下次啟動時還原。
- `說明`：開啟線上文件、問題回報頁面或「關於」視窗。

### 3. 工具列

- **開啟**：選擇並開啟地圖或 Scenario 檔案。
- **重新載入**：重新讀取地圖、重新整理已啟動的 3D 場景，並重新載入目前的單模型預覽；效果與 `F5` 相同。
- **重新載入線形**：重新讀取地圖，更新線形和放置資料，並儘量重用已載入的 3D 場景模型、保留攝影機位置，適合外部修改路線程式碼後重新整理預覽。
- **編輯模式**：啟用或關閉編輯功能。首次啟用會顯示風險提示。
- **新增地圖元素**：啟用編輯模式並完成編輯資料載入後，開啟「新增地圖元素精靈」。
- **儲存**：把已套用的地圖修改和 Scenario 修改寫入原始檔，快速鍵為 `Ctrl+Shift+S`。資源清單和自訂訊息的草稿須先在各自表格中套用。
- **撤銷**：確認後，放棄全部待儲存修改、資源清單及自訂訊息草稿和 Scenario 修改，將記憶體工作副本恢復到上次儲存時的狀態。
- **車站跳轉**：從下拉清單選擇車站，同時定位 2D 檢視；3D 場景已啟動時也會移動場景攝影機。
- **跳轉到里程(m)**：輸入數字後點選「跳轉」，或在輸入框中按 `Enter`。3D 場景已啟動時也會同步移動攝影機。

全域快速鍵為 `F5`（重新載入）和 `Ctrl+Shift+S`（儲存）。2D、3D 畫布操作分別見第 5、9 節。

### 4. 狀態列與主控台

#### 底部狀態列

- 左側的 `Err` 和 `Warn` 顯示錯誤、警告數量。點選該區域可檢視錯誤和警告摘要。
- 右側狀態文字顯示「載入中」「就緒」「正在套用更改」「已儲存」等目前狀態；耗時操作完成後還會顯示用時。

#### 主控台視窗

主控台顯示完整的載入、剖析、模型和編輯記錄。遇到地圖無法開啟、模型缺失或儲存失敗時，應先檢視這裡。

套用、儲存和刪除的總用時顯示在狀態列，分階段耗時記錄在主控台的 `edit timing:` 記錄中。

- **清除**：清空記錄，同時把錯誤和警告計數歸零。
- **複製**：把全部記錄複製到剪貼簿，便於回報問題。
- 記錄停留在底部時自動跟隨新內容；向上滾動可停留檢視歷史記錄。

### 5. 2D 畫布

2D 檢視上方可選擇「移動」或「測量」模式。網格設為「固定」時保持在螢幕上，設為「可移動」時跟隨地圖平移、縮放和旋轉，設為「無」時隱藏。上下拖曳平面圖與下方圖表之間的分隔條可調整高度；左右拖曳兩張圖表之間的分隔條可調整寬度。

#### 平面圖：移動模式

| 操作 | 功能 |
| --- | --- |
| 按住滑鼠左鍵拖曳 | 平移平面圖 |
| 滾動滑鼠滾輪 | 縮放平面圖 |
| `Shift` + 滑鼠滾輪 | 每次旋轉平面圖 5° |
| `Ctrl` + 滑鼠左鍵拖曳 | 圍繞畫布中心連續旋轉 |
| 按兩下滑鼠左鍵 | 恢復為適合視窗的完整範圍 |
| 按一下滑鼠右鍵標記 | 開啟定位、查詢或預覽選單；編輯模式下還會顯示「屬性/編輯」和「刪除」 |

觸控操作中，單指拖曳用於平移，雙指手勢可同時平移、縮放和旋轉；長按標記相當於按一下滑鼠右鍵。

#### 縱斷面圖與曲線半徑圖

縱斷面圖顯示里程與標高；曲線半徑圖區分左、右曲線並標註半徑。滑鼠左鍵拖曳可平移，滾輪縮放橫向里程範圍；「移動」模式下按兩下可恢復檢視範圍。觸控時橫向雙指縮放調整里程範圍，縱斷面圖還支援縱向雙指縮放標高軸。

#### 平面圖與圖表：測量模式

- 把滑鼠移到軌道附近，可即時檢視里程、標高、坡度、曲線半徑和目前限速。
- 在平面圖、縱斷面圖或曲線半徑圖中按兩下，可把三個檢視的測量位置同步到該里程。

#### 標記、定位與編輯

- 透過 `輔助資訊` 選單選擇要顯示的標記。
- 開啟「曲線半徑」後，`Curve.Interpolate` 端點以綠色標記顯示，旁邊標註求值後的有符號半徑；省略半徑時顯示繼承值。
- 右鍵標記可定位到對應表格；有 3D 物件的項目還可定位到 3D 場景。
- 啟用編輯模式後，可右鍵受支援的標記進行「屬性/編輯」或「刪除」。自軌道曲線/坡度及其他軌道的編輯控制點在此模式下顯示；`Curve.Interpolate` 和 `CG`/`CC`/`CF` 標記按各自開關顯示。
- 縱斷面圖和曲線半徑圖中，已配對的曲線/坡度變化點提供編輯選單。

#### 背景圖

在 `2D檢視` 選單的「背景圖」分組點選「匯入」選擇圖片。「顯示」控制圖片可見性，「調整」可設定位置、寬高、旋轉角度和亮度。

地圖至少有兩個車站時，可用「按車站對齊」完成對齊：

1. 選擇 `Station 1`，點選「在平面圖選點」，在背景圖上按兩下該站的位置。
2. 選擇另一座車站作為 `Station 2`，以同樣方式選取位置。
3. 點選「套用」或「確定」，計算圖片的位置、比例和旋轉角度。

背景圖路徑和對齊參數按目前地圖或 Scenario 入口記錄，重新開啟時恢復。

### 6. 地圖資訊表格

#### 通用操作

- 在 `地圖資訊清單` 中開啟所需表格。在提供定位選單的里程儲存格上右鍵，可定位到平面圖或已啟動的 3D 場景。
- 右鍵原始檔或資源檔案路徑，可開啟其所在目錄。將滑鼠停在路徑上，通常會顯示原始參數和剖析後的絕對路徑。
- 佈景模型、號誌顯示狀態、音效檔案和 3D 音效檔案表格可展開「尋找」，選擇部分或完全相符，輸入後按 `Enter` 或點選「尋找」，用上下箭頭切換結果。英文比對不區分大小寫。
- 「尋找未使用…」會醒目提示目前地圖中未被引用的定義。佈景檢查包含放置、連續佈景、背景、號誌和其他列車引用；普通音效檢查包含車站到達/出發音效，並計入目前清單草稿。
- 在地圖放置列中右鍵資源 key，可跳到對應的佈景模型、號誌顯示狀態或音效定義。
- 啟用編輯模式後，右鍵可編輯元素的儲存格可選擇「屬性/編輯」或「刪除」；部分表格支援按兩下開啟「屬性/編輯」。

#### 車站與佈景

- **車站清單**：上半部分顯示 `Station.Put` 的停車里程、開門方向和前後停車容差，透過右鍵「屬性/編輯」修改；下半部分顯示 `Station.Load` 載入的站名、到發時刻、停車時間和音效等定義，採用列內編輯。
- **地圖佈景**：顯示 `Structure.Put` 和 `Structure.Put0`。可定位到平面圖、3D 場景或對應模型定義。
- **地圖佈景（PutBetween）**：顯示 `Structure.PutBetween`，用於檢視兩條軌道之間的變形佈景。
- **佈景模型**：顯示 structureKey 和模型路徑。右鍵 key 可預覽模型或把該 key 填入已開啟且型別符合的新增元素精靈。
- **連續佈景**：將同名 `Repeater.Begin`/`Begin0`/`End` 顯示為區間，可定位起點、終點或變化點。屬性視窗用於調整各段參數、模型順序和結束里程，具體操作見第 10 節。
- **其他列車**：顯示其他列車定義、停止位置和唯讀的 `Train.Enable` 時間。可逐條控制路徑顯示，並把停止位置定位到平面圖。

#### 軌道幾何、號誌與閉塞

- **其他軌道**：透過「顯示」或「全選」控制 2D/3D 軌道顯示，起止里程和顏色用於調整 2D 檢視。編輯模式下可右鍵 `Key` 重新命名同名 `Track[...]` 陳述式；佈景、號誌和 Repeater 中的軌道引用須另行修改。
- **軌道變位、黏著特性變化點、限速點**：顯示相應變化位置，並可定位到 2D/3D。限速 Begin 和 End 可以獨立存在；End 只編輯里程。
- **號誌顯示狀態**：顯示號誌顯示狀態定義和引用的佈景 key，可反查佈景模型。
- **地圖號誌**：顯示 `Signal.Put` 的位置和參數。「顯示」核取方塊控制該號誌在平面圖中的標記。
- **閉塞**：顯示 `Section.Begin`/`BeginNew` 的號誌索引，以及 `Section.SetSpeedLimit`/`Signal.SpeedLimit` 的顯示狀態限速。透過「屬性/編輯」中的 `+`、`-` 和上下箭頭增刪、排序參數；顯示狀態限速可用 `null` 表示不限速。表格最多顯示 508 個參數，完整清單可在屬性視窗檢視。
- **應答器**：顯示並定位 `Beacon.Put`。
- **變數**：按不區分大小寫的變數名分組顯示全部指派。將滑鼠停在項目上可檢視原運算式；該表唯讀。

#### 音效與效果

- **音效檔案、3D音效檔案**：顯示音效 key、檔案路徑和緩衝區數量，並可開啟檔案所在目錄或把 key 填入符合的新增元素精靈。
- **地圖音效、地圖3D音效、走行音變化點、輪緣摩擦音效變化點、道岔音效播放點**：顯示並定位播放點或變化點。
- **背景變化點、駕駛台亮度變化點、霧效果變化點、舊式霧效果變化點、繪製距離變化點**：顯示並定位對應效果。
- **光照**：分別顯示 `Light.Ambient`、`Light.Diffuse` 的 RGB 和 `Light.Direction` 的 pitch/yaw。編輯模式下直接修改參數並點選本視窗「套用」，再用工具列「儲存」；缺少的項目可點選「新增」，已有項目可點選「刪除」。
- **Scenario 檔案**：顯示已開啟的 Scenario 欄位及候選。編輯和儲存方式見第 2 節。

#### 資源清單的列內編輯

開啟編輯模式後，車站定義、佈景模型、號誌顯示狀態、音效檔案和 3D 音效檔案使用以下列內編輯方式：

- 按兩下可編輯儲存格開始輸入，按 `Enter` 或離開儲存格暫存草稿；右鍵可在上方/下方新增列、上移/下移整列、清空儲存格或刪除整列。資源檔案路徑儲存格還提供「選擇檔案」。
- 空清單可透過「新增列」新增第一條記錄。
- 「選擇檔案」會儘可能儲存相對路徑；無法產生相對路徑時使用絕對路徑。
- 號誌顯示狀態主列與眩光列作為整體移動或刪除。新增主列預設為 6 個欄位，可透過「新增眩光」新增眩光列。
- 點選表格中的「套用」更新記憶體預覽；各表格草稿全部套用後，點選工具列「儲存」寫入檔案。

號誌顯示狀態清單依各 CSV 列的實際欄位數顯示，保留尾端空欄位。斜線表示該列沒有對應欄位，既有的空白欄位可直接編輯。表格最多顯示 509 個佈景鍵欄，超出部分保留在來源資料和草稿中，並顯示提示。

- 右鍵 CSV 儲存格，可在目前列最右側新增一格、刪除尾端空白格或刪除最後一格。主列與眩光列可有不同欄位數。
- 「對齊所有欄」將各列補齊至最大欄位數；「在右側新增欄」和「刪除最右側欄」分別為各列增減一格；「刪除全部右側空白」裁去各列尾端空欄位。
- 各列至少保留第一個 CSV 欄位和一個可為空的佈景鍵欄位。眩光列的第一個欄位固定為空，整列透過「刪除眩光」移除。
- 刪除非空的最後一格前會要求確認。批次欄位操作也包含顯示上限之外的欄位。

既有的多列連續眩光資料會合併顯示，編輯時須保持合併後的欄位總數；移動或「刪除眩光」作用於整組眩光資料。完成儲存格或欄位操作後，統一按「套用」→「儲存」提交。

每張地圖可載入各類資源清單各一份。尚未載入時，點選表格中央的「新增或匯入檔案」；替換時，右鍵頂端「檔案路徑」，選擇「更換檔案...」。若該清單有未套用或未儲存的修改，程式會確認後丟棄該清單的修改。

komapedit 相容 Station List 0.04+、Structure List 1.00+、Signal Aspects List 和 Sound List 2.00+。普通音效與 3D 音效使用同一種 Sound List 格式。資源清單的標準註解符為 `#`，komapedit 還相容 CSV 雙引號外的 `//` 註解。

### 7. 檔案結構圖與文字預覽

從 `輔助資訊 -> 其他 -> 檔案結構圖` 開啟該視窗。入口地圖位於最左側，右側按層級顯示它所 Include 的子地圖；將滑鼠停在節點上可檢視 Include 參數和絕對路徑。

#### 檢視檔案

- 右鍵有效節點，選擇「預覽文字」，可在唯讀文字預覽視窗中檢視原始碼和行號。
- 「屬性/編輯」視窗中的原始檔名也提供「預覽文字」。地圖和資源清單的文字預覽會隨「套用」重新整理，可用於檢查儲存前的原始碼結果。
- 「在檔案總管中開啟」可開啟目標目錄；目錄不存在時在主控台報錯。
- 缺失或無效的 Include 目標顯示為紅色節點，其文字預覽、匯入和新增子地圖操作禁用。

#### 編輯 Include

以下操作要求編輯模式：

- **更換檔案...**：選擇新的 `.txt`/`.csv` 子地圖，改寫上級檔案中的 Include 路徑。優先使用相對路徑，失敗時使用絕對路徑。
- **解除引用**：刪除父檔案中的 Include 陳述式。若後續陳述式仍依賴該子地圖提供的內容，程式會阻止操作。
- **匯入子地圖...**：選擇已有 BVE 地圖，並在目前節點代表的原始碼檔案中暫存新的 Include。
- **新增子地圖...**：在新檔案路徑建立 UTF-8 無 BOM、CRLF、檔頭為 `BveTs Map 2.02:utf-8` 的空白子地圖，並暫存 Include。

新增 Include 放在該檔案第一個距離陳述式之前的最後一個 Include 之後；若該處沒有 Include，則放在第一個距離陳述式之前；兩者均無則附加至檔案尾端。修改會立即更新預覽，點選「儲存」後寫入父地圖。

在 komapedit 中，各 Map 檔案的 `distance` 從 `0` 開始，Include 結束後恢復父檔案里程，普通 `$變數` 共用。相對父地圖放置子地圖時，可先寫 `$dis=distance;`，再在子地圖內用 `$dis+偏移量;` 設定里程。

### 8. 3D 模型預覽

從 `3D檢視 -> 佈景模型預覽` 開啟視窗，再從「佈景模型清單」右鍵某個 structureKey，選擇「預覽模型」。

- **模型清單**：開啟佈景模型清單。
- **重新載入**：重新讀取目前模型及其材質、貼圖。
- **清除**：從預覽視窗移除目前模型。
- **背景顏色**：選擇任意 RGB 顏色，或使用白、黑、灰、藍、綠預設顏色。
- 在畫布中按住滑鼠左鍵拖曳可旋轉模型；滾動滑鼠滾輪可縮放。

模型或貼圖載入失敗的詳情可在主控台檢視。

### 9. 3D 場景預覽

從 `3D檢視 -> 3D場景預覽` 開啟視窗，點選「啟動3D場景預覽」。也可在 `選項 -> 3D畫布設定` 中開啟「開啟地圖時自動載入場景預覽」（預設關閉），隨開啟或重新載入地圖自動啟動。

視窗頂端提供「啟動3D場景預覽」「重新載入（模型）」和「關閉」：

- 「重新載入（模型）」重新讀取場景使用的模型，保留目前地圖和攝影機位置。
- 「關閉」釋放目前場景；視窗本身仍可保持開啟。

#### 移動模式與快速鍵

把滑鼠停在 3D 畫布上時可使用以下操作：

鍵盤移動在「移動」「選擇」和「里程選擇」三種模式中都可用；滑鼠左鍵拖曳轉動視角只在「移動」模式中可用。

| 操作 | 功能 |
| --- | --- |
| 滑鼠左鍵拖曳 | 在「移動」模式中轉動視角 |
| `W` / `S` | 沿路線向前 / 向後移動 |
| `A` / `D` | 向左 / 向右移動 |
| `R` / `F` | 向上 / 向下移動 |
| 按住 `Ctrl` | 加快上述鍵盤移動速度 |
| `X` | 在目前里程恢復到自軌道中心上方的預設攝影機姿態 |

攝影機速度可在「3D畫布設定」中調整，也可透過工具列跳轉到車站或指定里程。攝影機最遠可後退至自軌道起點前 100 m。開啟「平面圖上顯示目前位置」後，2D 平面圖同步顯示攝影機位置。

#### 選擇模式

- 把滑鼠移到場景物件或標記上可醒目提示目標。
- 右鍵物件或標記可定位到對應的地圖資訊表格；連續佈景還可跳到起點或結束/變化位置。
- 右鍵號誌機，選擇「切換號誌顯示狀態」，可按索引和佈景 key 切換該物件的預覽模型。
- 編輯模式下，同一選單還會提供「屬性/編輯」和刪除操作。編輯操縱器見第 10 節。

#### 里程選擇模式

- 滑鼠附近會顯示自軌道平面上最近的整公尺橫斷面和里程標籤。
- 編輯模式下，右鍵該位置可選擇「在目前里程新增地圖元素」，精靈會自動填寫 distance。

#### 場景疊加資訊與設定

畫布顯示攝影機位置、目前曲線半徑/超高、坡度、限速、閉塞號誌速度和下一站資訊。`Curve.Interpolate` 區間顯示兩端的半徑、超高和曲線方向；兩端半徑均為零時顯示「直線」。底部顯示場景區塊、執行個體、模型載入數量和影格率。

FPS 顯示場景畫布的重新整理頻率，空閒時保留上次統計值。

在 `選項 -> 3D畫布設定` 中可調整：

- **繪製距離**：控制攝影機前方的場景範圍；開啟「繪製距離依據地圖陳述式調整」後，結合 `DrawDistance.Change` 限制顯示範圍。
- **霧效果**：切換地圖中的霧預覽。
- **編輯用元件尺寸、攝影機移動速度**：調整操縱器大小和鍵盤移動速度。
- **效能警告**：按目前繪製的執行個體數量著色提示，超過「警告標準」為黃色，超過「嚴重警告標準」為紅色。

相關標記的顯示狀態與 `輔助資訊` 選單同步。

霧預覽支援 `Fog.Interpolate`/`Fog.Set` 指數霧，以及相容陳述式 `Legacy.Fog` 的線性霧。同類霧節點間漸變，異類節點間在後一節點切換。`Legacy.Fog` 的 start/end 使用攝影機深度距離（公尺），RGB 為 0–255；零里程設定立即生效，前後均為線性霧時，後續設定在 25 公尺內過渡。兩類霧均可從表格或標記編輯，並在精靈的「效果」分類中新增。

#### 場景標牌

透過 `輔助資訊` 控制標牌顯示。開啟「曲線半徑」後，`Curve.Interpolate` 內插點顯示半徑、超高和曲線方向；半徑為零時顯示 `Intpl. 0`。標牌支援拾取、醒目提示，以及編輯模式下的右鍵編輯和刪除。

### 10. 編輯、新增與儲存

#### 開始編輯前

首次啟用工具列「編輯模式」時會顯示提示，可勾選「不再顯示」並確認。

開啟後等待編輯資料載入完成，再進行修改。在屬性視窗、光照視窗或精靈中填寫的內容，先點選「套用」再離開。關閉編輯模式、開啟其他檔案、重新載入或離開程式時，程式會提示處理待儲存更改。

#### 草稿、套用、儲存與撤銷

地圖與資源清單的編輯流程如下：

1. **修改草稿**：在「屬性/編輯」、資源清單或精靈中輸入內容；部分物件可即時預覽。
2. **套用到預覽**：點選視窗中的「套用」，驗證並重新剖析記憶體工作副本，重新整理 2D、表格和 3D 預覽。
3. **儲存到磁碟**：點選工具列「儲存」或按 `Ctrl+Shift+S`，將全部已套用更改寫入對應的地圖、Include 或資源清單檔案。

資源清單和自訂訊息的草稿須全部套用後才能儲存；Scenario 輸入框中的修改直接由工具列「儲存」提交。工具列「撤銷」恢復上次儲存時的記憶體狀態；要讀取外部編輯器寫入的內容，使用「重新載入」。

儲存前會重新剖析並核對修改結果，保留原檔案編碼、BOM 和換行格式。新文字超出原編碼範圍，或檔案已被其他程式修改時，程式會阻止儲存並提示原因。

#### 編輯或刪除已有地圖元素

1. 在表格、2D 標記或 3D 標記上右鍵，選擇「屬性/編輯」。
2. 在視窗中確認原始檔、原始碼位置和原始陳述式，再修改欄位。
3. 點選「套用」重新整理記憶體預覽。
4. 檢查 2D、表格和 3D 結果；確認無誤後使用工具列「儲存」。

支援編輯車站、佈景、號誌、應答器、連續佈景、閉塞、限速、曲線與坡度、其他軌道、軌道變位、音效、背景、黏著、駕駛台亮度、霧、光照參數、繪製距離和先行列車通過點等。右鍵「刪除」會將刪除操作套用到預覽，儲存時寫入原始檔。

`Structure.Put`/`Put0` 和 `Repeater.Begin`/`Begin0` 可透過「新增座標偏移」或「去除座標偏移」切換形式；清除非零偏移前需確認。短式 `Signal.Put` 在編輯 Z、旋轉、傾斜或跨度前，需確認轉換為完整形式。

#### 連續佈景的分段編輯

- 開啟 Repeater 的「屬性/編輯」，用「上一個」「下一個」切換同名連續佈景的變化段。
- 用佈景鍵清單旁的 `+`、`-` 和上下箭頭增刪、排序迴圈放置的模型。
- 「插入變化點」開啟預填目前參數的精靈；填寫新里程和參數後套用。末段尚無 End 時，可用「新增結束位置」補上。
- 多段區間的刪除選單提供「全部刪除」「刪除對應變化點」「修剪至變化點」和「從變化點開始」，分別處理整條鏈、單個變化點、後續區段或前段。操作套用到預覽後，再統一儲存。

#### 在 3D 場景中即時調整

開啟「屬性/編輯」後，可拖曳受支援物件的操縱器調整草稿，再按上述流程套用、儲存。

- `Structure.Put`、完整式 `Signal.Put` 和 `Repeater.Begin` 可使用 X/Y/Z 軸調整座標。
- `Sound3D[soundKey].Put(x, y)` 的 X/Y 軸以 0.001 m 調整相對位置，Z 軸以整公尺調整里程。
- `Structure.Put0` 和 `Repeater.Begin0` 使用 Z 軸調整整公尺里程；新增座標偏移後可使用完整座標操縱器。
- 帶顯式 End 的 Repeater 可在結束位置透過 Z 軸調整整公尺結束里程。
- `Structure.PutBetween` 使用 Z 軸調整整公尺里程，並即時重新計算變形後的模型。

#### 新增地圖元素精靈

從工具列「新增地圖元素」開啟精靈，或在 3D「里程選擇」模式中右鍵目前里程開啟。選擇目標原始檔、範本並填寫參數；已載入的地圖原始檔（包括空白或無距離陳述式的檔案）均可作為目標。

新增或移動元素時，程式會自動安排距離陳述式並保留其他陳述式與註解。需要手動定位時，在文字預覽中選中醒目提示的陳述式邊界，點選「確定」繼續；需要指定距離運算式時，在提示框中填寫原始字串並點選「套用」。

精靈按以下類別提供目前支援的元素：

- **佈景**：`Structure.Put`、`Put0`、`PutBetween`，以及 `Repeater.Begin`/`Begin0`/`End`。
- **車站**：`Station.Put`。
- **軌道幾何**：曲線、坡度、軌距、曲線中心與內插函式、軌道變位和黏著變化。
- **其他軌道**：位置、X/Y 內插和超高相關的 `Track.*` 陳述式。
- **號誌**：號誌、限速、閉塞、號誌速度、應答器和 `PreTrain.Pass` 先行列車通過點。
- **音效**：地圖音效、3D 音源、走行音、輪緣摩擦音和道岔音。
- **效果**：背景、駕駛台亮度、霧、光照參數和繪製距離。
- **其他**：自訂訊息，作為註解放在地圖檔頭下方。

「套用」新增元素並重新整理預覽；「套用並編輯」還會關閉精靈，開啟新元素的「屬性/編輯」視窗或「自訂訊息」分頁。Repeater 的變化點精靈使用「套用」。

各範本的填寫要點：

- **Repeater**：可新增 Begin、End 或兩者；成對新增時，結束里程須大於或等於起始里程，同名成對區間須避免重疊。區間內的參數變化使用「插入變化點」。
- **曲線與坡度**：可分別新增起點、終點，或成對建立。曲線起點可選 `Curve.Begin` 或 `Curve.Change`，終點使用 `Curve.End`；坡度使用 `Gradient.Begin`/`End`。Begin/End 可配套建立緩和段起點，`Curve.Change` 直接修改半徑。
- **曲線內插點**：`Curve.Interpolate` 的 distance 必填，radius 與 cant 預設均為 `0`。可取消 cant 產生單參數形式，或取消 radius 產生無參數形式。
- **其他軌道**：可選尾參數須連續啟用，例如填寫 `radiusV` 前須包含 `radiusH`。新的 trackKey 會建立其他軌道，數值鍵與帶引號的字串鍵分別處理。
- **先行列車通過點**：`passTime` 可填寫 `hh:mm:ss`，或從午夜起算的秒數；將滑鼠停在輸入框上可檢視格式提示。
- **光照**：精靈在里程 `0` 新增，RGB 填寫 `0`–`1`；每類光照陳述式在整個地圖（含 Include）中各設一條。

#### 自訂訊息（Message from Creator）

在新增地圖元素精靈中選擇「其他 → 自訂訊息」，選定地圖原始檔並填寫單行訊息。套用、儲存後，訊息以以下註解格式寫在檔頭空白行之後；已有訊息時追加到訊息區塊末尾：

```plaintext
BveTs Map 2.02

//--kme--message-from-creator:"content"
```

訊息使用普通 BVE `//` 註解儲存，內容按原文處理，保留空格、引號和反斜線。可填寫空訊息；內容須為單行且無 NUL 字元。

開啟地圖或 Scenario 時，會展示主地圖及已載入 Include 中的訊息，多條訊息可翻頁檢視。重複引用同一檔案時，同一條訊息僅展示一次。勾選「下次不再顯示」並確認後，程式會按主地圖記住該選擇。

透過「輔助資訊 → 其他 → 自訂訊息」可隨時檢視原始檔、行號與內容。輸入關鍵字並按 `Enter` 或點選「尋找」，可尋找原始檔或訊息內容，用上下箭頭切換結果。

開啟編輯模式後，按兩下內容儲存格編輯，按 `Enter` 或離開儲存格暫存草稿，`Esc` 取消目前輸入；右鍵「刪除整列」暫存刪除操作。完成後點選頁內「套用」，再透過工具列「儲存」。

#### 新增檔案精靈

從 `檔案 -> 新增...` 開啟，可建立 Map、Scenario、Structure List、Signal Aspects List、Sound List、Sound3D 使用的 Sound List 和 Station List。

1. 選擇檔案類型，輸入不含副檔名的名稱，選擇 `.txt` 或 `.csv`，再選擇目錄。
2. 資源清單可透過「匯入檔案」預填已有 `.txt`/`.csv` 的名稱、目錄和副檔名，再視需要修改。
3. 建立 Scenario 時填寫所需欄位，留空欄位會省略。`Route`、`Vehicle` 和 `Image` 可透過「選擇檔案」填入相對路徑。
4. 目前已載入地圖時，建立 Map 或資源清單須開啟編輯模式，並在「在以下檔案中引用」確認目標原始檔；尚未載入地圖時可直接建立獨立檔案。
5. 點選「確定」建立或重用檔案。建立子地圖後，先儲存父地圖中的引用，再開啟子地圖；獨立地圖或 Scenario 可選擇「確定並載入」。

已有普通檔案會原樣重用；新檔案使用 UTF-8 和 CRLF，地圖與資源清單包含標準檔頭，Scenario 按標準欄位順序寫入內容。

Scenario 範本提供 `Title`、`Route`、`RouteTitle`、`Vehicle`、`VehicleTitle`、`Author`、`Image`、`Comment` 八個欄位。路徑欄位各接受單一路徑，欄位值須避開 `#`、`;` 等註解字元；多候選路徑與權重可在載入後的「Scenario 檔案」分頁編輯。

精靈立即建立檔案，`include` 或相應 `*.Load` 引用則先套用到地圖預覽，再由工具列「儲存」寫入。每種資源清單可引用一份；更換已引用的檔案請使用對應表格頂端「檔案路徑」的右鍵選單。

## 附錄：CSV 資料格式

### 自軌道幾何 CSV（匯出）

透過 `檔案 -> 匯出 CSV...` 匯出目前幾何取樣結果。檔名格式：

```text
<匯出目錄名>_owntrack.csv
```

表頭：

```csv
#distance,x,y,z,direction,radius,gradient,interpolate_func,cant,center,gauge
```

欄位說明：

| 欄位             | 說明                                             |
| ---------------- | ------------------------------------------------ |
| distance         | 地圖絕對距離，單位 m                             |
| x                | 考慮縱坡投影後的自軌道平面 X 座標，單位 m       |
| y                | 考慮縱坡投影後的自軌道平面 Y 座標，單位 m       |
| z                | 標高，單位 m                                    |
| direction        | 軌道方向角，單位 rad                             |
| radius           | 有符號曲線半徑，單位 m；正為右曲線，負為左曲線，0 為直線 |
| gradient         | 坡度，單位 ‰                                    |
| interpolate_func | 內插型別，`0` 表示正弦半波緩動，`1` 表示線性緩動 |
| cant             | 超高，單位 m                                    |
| center           | 超高旋轉中心的橫向座標，單位 m                  |
| gauge            | 軌距，單位 m                                    |

### 其他軌道幾何 CSV（匯出）

每條其他軌道會匯出一個 CSV。檔名格式：

```text
<匯出目錄名>_<trackKey>.csv
```

trackKey 中的 `\ / : * ? " < > |` 會替換為 `_`，空 key 使用 `root`。不同軌道的匯出檔名須互不重複。

表頭：

```csv
#distance,x,y,z,interpolate_func,cant,center,gauge
```

欄位說明：

| 欄位             | 說明                                        |
| ---------------- | ------------------------------------------- |
| distance         | 地圖絕對距離，單位 m                        |
| x                | 依據投影後的自軌道計算出的其他軌道平面 X 座標，單位 m |
| y                | 依據投影後的自軌道計算出的其他軌道平面 Y 座標，單位 m |
| z                | 其他軌道標高，單位 m                         |
| interpolate_func | 超高內插型別，`0` 表示正弦半波緩動，`1` 表示線性緩動 |
| cant             | 超高，單位 m                               |
| center           | 超高旋轉中心的橫向座標，單位 m             |
| gauge            | 軌距，單位 m                               |

CSV 匯出軌道幾何資料，數值固定保留 6 位小數。
