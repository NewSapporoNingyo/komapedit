### S3.1 按钮图标效果确认（已完成）

原有五个视图模式按钮通过独立 Release 目录、单屏 100%／150% 缩放和六语提示验收。主工具栏、2D 网格、控制台和列表图标，以及不同 DPI 的双屏切换已完成人工验收。

1. 在 [`/icons`](../icons/) 制作“移动、测量、选择、里程选择、平移、旋转、编辑、应用”的 SVG。两种视图共用“移动”图标。逐个检查图案是否符合按钮功能，重点区分视图移动与操纵器平移、元素选择与里程选择。
2. SVG 作为设计源文件，按各档目标尺寸导出带抗锯齿的透明 PNG。Windows 缩放比例与尺寸对应为 100%／16 px、125%／20 px、150%／24 px、175%／28 px、200%／32 px、250%／40 px、300%／48 px、400%／64 px、500%／80 px。[`komapedit.rc`](../komapedit.rc) 只将各档 PNG 作为 `RCDATA` 编入 EXE，CMake 将 PNG 列为资源编译依赖。
3. 用 16 px 乘以当前窗口的 `ImGui::GetWindowDpiScale()` 并取整，得到显示尺寸。选用覆盖目标尺寸的最小图源，以 80 px 为图源上限。用 WIC 从资源内存解码，按图标和尺寸缓存 DX11 纹理，按整像素位置绘制。上传时将所有像素的 RGB 统一为白色，保留抗锯齿覆盖率作为直通 Alpha，由 ImGui 按主题和按钮状态着色，避免深浅底色上的黑边和白边。
4. 在 [2D 模式控件](../src/canvas2d/canvas2D.cpp)的“移动／测量”和 [3D 场景工具栏](../src/main_window/scene_preview_lifecycle.cpp)的“移动／选择／里程选择”原位以图标按钮替换 `ImGui::RadioButton`，复用原有模式状态和切换行为。
5. 主工具栏的七项操作、2D 网格的三种互斥模式、控制台的清除和复制、列表的执行查找和查找未使用项采用图标按钮。复用六语操作名称作为提示，里程跳转使用字符 `→`。按钮用法见[用户手册](user-manual_zhcn.md#3-工具栏)。

**验收**

检查 SVG、各尺寸 PNG 和实际界面中的图形辨识度与边缘。验证缩放、跨不同 DPI 的显示器移动、模式切换、按钮状态和六语提示。在包含 EXE 和现有运行依赖的独立发行目录启动，确认各档图标均由 EXE 资源提供。

### S3.2 3D 画布操纵器平移／旋转的按钮切换（已完成）

3D 场景工具栏的视图模式组右侧提供“平移”和“旋转”图标。每帧同步检查器目标后，`Canvas3D` 提供旋转资格与当前模式。新目标从平移模式开始，当前模式键带选中描边并禁用。属性关闭、同步失败或目标仅支持位置编辑时，两键均禁用。

完整式 `Structure.Put`、`Repeater.Begin` 和 `Signal.Put` 支持两种模式。`Put0` 和 `Begin0` 通过检查器的坐标偏移控件转换，简式 `Signal.Put` 通过确认框转换。元素、标记和里程各用自己的右键菜单。[操作说明](user-manual_zhcn.md#在-3d-场景中实时调整)

**验收**

实机验证了属性开关、目标切换、同步失败与恢复、简式转换、仅位置目标、鼠标与键盘切换、三轴旋转和三类右键入口。100% 和 150% 单屏缩放下检查了按钮外观，并核对六语提示。

Debug headless 契约通过模式切换、三轴变换、15° 吸附及取消恢复检查。拖动中同时按住 Shift 和拖动中按 Esc 的两种操作已完成人工复核。

### S3.3 2D 画布线形编辑功能（已完成）

1. **接入编辑模式。** 平面图、纵断面图和曲线半径图共用移动、测量和编辑三种互斥模式。进入编辑时清除测量线和读数。全局编辑可用时启用铅笔按钮，关闭全局编辑时恢复进入编辑前的导航模式。启动时从设置恢复移动或测量模式。网格选项右侧的“应用”按钮在有草稿且编辑操作空闲时启用。
2. **绑定目标并拖动端点。** 在[快照接收](../src/main_window/map_snapshot_hydration.cpp)与[标记缓存](../src/canvas2d/canvas2d_marker_cache.cpp)中，将曲线端点、缓和曲线端点、坡度变化点、曲线区段和派生事件关联到稳定编辑 ID。已配对的缓和起点通过共享过渡链定位主语句，孤立起点保持只读。平面图将鼠标投影到手势开始时的轨道折线，纵断面图将水平位移换算为里程差。二者共享相邻端点约束、以起始里程为基准的 5 m 吸附和草稿。纵断面拖动时锁住图表轴，鼠标旁显示候选里程。
3. **用滚轮调整半径。** 命中曲线阴影时，滚轮按 5 m 步长修改该区段所属语句的显式半径，向上增大，向下减小。正值为右曲线，零为直线，负值为左曲线。跨零的一格先停在 0 m，例如 `+2 → 0 → −5 m`。同一语句的半径标签优先显示在可见圆曲线段，缓和段提供可见时的候补位置。半径为零时保留区段命中范围，画布其它区域沿用缩放与旋转操作。
4. **生成草稿预览。** 共享[自轨道几何计算](../src/maploader/maploader_geometry.cpp)，用已求值事件和草稿参数更新平面线形与纵断面。工作线程合并输入并复用最早受影响边界前的轨道。拖动结束或滚轮停顿后，按同一里程的新旧轨道位姿重投影其它平面标记和轨道附属路径。绘制和命中共用投影结果。缓存按模型、草稿和采样参数接收当前结果，静止时复用。
5. **接入应用和保存。** 将草稿按字段合并到[现有编辑批次](../src/main_window/edit_ledger.cpp)，在界面绘制结束后提交。完整重解析成功后更新内存工作副本、清除草稿并统一刷新表格、2D 和 3D。里程歧义复用现有位置选择和重试，失败时保留草稿与原工作副本。有未应用的画布草稿时，保存提示先在 2D 窗口应用。保存将内存工作副本提交到磁盘。切换画布模式时保留草稿，Esc 取消当前拖动，还原清除草稿。关闭全局编辑、重载、切换文件和退出时，将草稿纳入既有未保存变更处理。

实施前按官方 Map 缓存建立合规矩阵。端点编辑覆盖现有 `Curve.Begin / BeginCircular / Change / End / Interpolate`、`Gradient.Begin / BeginConst / End / Interpolate` 及配对的 `BeginTransition`。沿用原语句形式，保留未编辑参数及其表达式、注释、编码、换行和 Include 来源。

**验收**

- 检查三种模式互斥、全局编辑与忙碌状态、六语提示、三类端点的双向拖动、非整 5 m 初值、重叠标记选择、正负半径和双向跨零。实测命中范围、标签位置和连续操作反馈。
- 验证预览、应用和保存重开后的几何一致，覆盖连续应用、取消、还原、Include、表达式里程、里程歧义和失败后保留草稿。运行类型化编辑、快照、坡度投影和六语言相关契约，扩展 `--debug-headless-own-track-edit` 和 `--debug-headless-plan-bench` 验证。
- 使用相同线路、采样参数和 Debug 构建比较静止、连续拖动与滚轮操作，记录预览延迟、帧耗时和计算次数，沿用现有 2D 帧预算。

Debug 构建、七项 CTest、线形编辑契约和指定线路的保存重开通过。25 m 采样下，编辑静止、连续拖动和滚轮的帧耗时 p95 分别为 3.881、4.344 和 4.385 ms。实机验证了三类端点拖动、缓和段滚轮、草稿保存提示、内存应用及全局编辑关闭后恢复测量模式。

1. 确定数值与字符串赋值、变量重命名的交付范围，以及变量影响距离、资源键、路径和引用文件时的处理规则。
2. 为每次具体赋值记录源码位置、解析顺序和编辑身份，建立变更后的预期影响集合，覆盖后续读取、再次赋值和引用环境。
3. 实现已有赋值编辑，再实现指定位置新建赋值，两者通过类型化队列提交。完整重解析证明集合内的预期变化，集合外沿用现有语义与变量环境校验。
4. 验证同名多次赋值、定义先后、空文件、未使用变量、重复引用、随机重放、编码、连续编辑、还原和保存重开。

**完成条件：** 变量编辑和新建均作用于确定的赋值位置；下游变化符合预期影响集合，非目标区域与磁盘并发保护保持有效。

## S18 跨里程相对位置组

预设与批次复用 [S15](#s15)，持久关联复用 [S14](#s14)，表达式基准复用 [S16](#s16)。

**主要位置：** 预设成员模型、距离解析与插入、共享链关联、整组预览。

1. 为组合确定参考成员、相对里程、成员顺序、资源映射，以及单文件或跨文件、一次性模板或持续关联的覆盖范围。
2. 先完成固定数值偏移的实例化，再扩展参考位置变化、整组复制和平移；表达式位置按各成员所在的变量环境验证。
3. 使用一个类型化批次处理成员距离和曲线、坡度、重复布景链关系，并交给后台队列。确定参考成员删除或替换后的组状态。
4. 验证正、负、零偏移，同里程先后，文件末尾、重复引用、链边界、环境改变、任一成员失败及保存重开。

**完成条件：** 组成员可按参考里程准确实例化、复制和平移；语句顺序与链关系正确，持久关联稳定，整组更新和还原结果完整。

## S19 C++ 插件系统

现有程序从固定目录加载地图和模型组件，运行时检查接口版本。为用户编写的 C++ 插件建设独立的宿主接口和 SDK。

1. 定义插件入口、接口版本与结构大小、数据所有权和加载生命周期。宿主检查接口版本并提供对应的加载诊断。
2. 支持插件注册工具命令，通过类型化接口获取所需设计输入和地图数据，返回计算结果、候选几何或检查报告。宿主负责结果展示和地图预览，将地图编辑批次交给 [S9](#s9) 的队列完整重解析并更新工作副本，显式保存提交磁盘。
3. 提供可独立构建的样例插件和开发教程，覆盖构建、安装、命令注册、调试和发布。验收加载样例、运行命令、结果传递和接口版本不兼容时的诊断。

**完成条件**

第三方开发者按教程构建并加载样例，可从编辑器调用样例命令，验证输入与结果的传递。

首批待开发插件为 [S20 纵曲线、缓和曲线与超高计算](#s20)、[S21 单开与 Y 形道岔自动计算](#s21)和 [S22 多地区工程规范检查](#s22)。

## S20 纵曲线、缓和曲线与超高计算插件

依赖 [S19](#s19) 的插件接口。现有曲线与坡度向导提供设计字段，轨道几何可按给定参数生成和取样。

1. 确定首批规范及版本、线路用途、设计速度来源、单位、取整规则和适用条件，为每类计算准备独立例题。
2. 由插件根据前后坡度和规范所需设计输入计算纵曲线长度，返回控制条件、坡变点位置及相邻过渡关系。
3. 由插件根据半径、轨距、限速和规范附加条件计算缓和曲线长度与超高，返回控制约束和推荐值，并处理方向与无解情况。
4. 宿主显示规范依据和计算过程，将结果回填现有向导。向导将生成普通 BVE 语句的结构化批次交给宿主编辑队列，重解析并验证几何。覆盖等坡、凸凹变坡、正负曲线、直线、不同轨距和区间重叠。

**完成条件**

宿主可调用插件完成两类计算，独立例题通过。向导回填后生成的语句和几何符合所选设计条件。

## S21 单开与 Y 形道岔自动计算插件

依赖 [S19](#s19) 的插件接口。现有轨道快照提供自轨道和他轨道几何，新建向导支持类型化批次。

1. 确定中心线布置或完整工程道岔的交付范围，明确前后里程、相对位置、切向、曲率、设计参数和轨道姿态的输入约束。
2. 插件读取相对位置及设计约束，求解单开与 Y 形道岔，返回候选几何、可行性和计算误差。
3. 宿主预览候选方案，由用户选择，再将生成普通 BVE 自轨道与他轨道语句的结构化批次提交后台队列。
4. 使用独立样例检查端点位置、切向连续性与曲率约束，覆盖对称 Y 形、反向、零长度、无解和多解。对生成源码重解析并取样验证。

**完成条件**

两类道岔均可由插件求解并在宿主生成。独立求解与重解析几何满足约定误差，失败时保留原编辑状态。

## S22 多地区工程规范检查插件

依赖 [S19](#s19) 的插件接口。宿主提供类型化的轨道取样和补充标注，插件执行版本化规则并返回检查报告。

1. 确定日本、中国和欧洲地区的具体标准、版本、适用线路及首批条文，以一套规范完成验证后扩展多种预设。
2. 明确道岔、曲线区间、到发线、站台和股道的工程实体及所需输入。补充信息通过 [S14](#s14) 的元数据与标记保存。
3. 先实现输入充分的半径和明确区间股道间距检查，再覆盖道岔、曲线间隔、到发线与站台长度，并检查区间最不利值。
4. 为每条规则提供通过、违反、临界、信息不足和不适用样例。插件报告规范条文、适用条件、输入来源、计算值、阈值和位置，宿主提供元素和区间定位。

**完成条件**

约定地区、版本和检查项目均有独立样例。插件结论可追溯到规范与输入，补充信息不足时输出对应状态，报告可在宿主定位到相关元素和区间。

## S23 线路发行版导出

**主要位置：** 新增线路导出流程、源码与引用数据、资源依赖收集、输出报告。

本阶段交付编辑器内的线路发行功能：向独立目录输出可分发的线路文件、资源和报告。

1. 确定从磁盘还是已应用工作副本导出，明确场景、车辆、地图、模型及声音的覆盖范围，以及随机求值、缺失资源和“实际使用”的判断规则。
2. 先交付只读依赖清单与预检，再交付保守复制、相对路径处理及报告。依赖收集覆盖模型纹理、信号辉光、车站音效、他列车和共享资源。他列车资源清单复用 [S13](#s13) 的类型化定义数据。
3. 实现 `Include` 展开，保持文件局部里程、变量执行顺序和相对路径语义；随后增加距离与变量表达式常量化、实际使用资源筛选。
4. 检查输入输出路径关系和文件名冲突，向独立输出位置生成产物；验证开发文件前后内容一致，并比较语句值、变量结果、引用、轨道几何和资源闭包。
5. 将产物移离开发目录，分别验证本项目加载和 BVE 运行，报告转换内容、资源来源、诊断和验证结果。

**完成条件：** 导出选项产生语义一致的线路；展开、常量化和资源筛选分别通过验证，产物脱离原目录仍可加载，开发目录保持原内容。

## S24 MCP 服务器

GUI 持有已发布的类型化数据和编辑账本。MCP 使用当前编辑器的工作副本，编辑请求接入 [S9](#s9) 的后台队列。

1. AI 客户端启动本机 MCP 适配器并通过 `stdio` 通信。适配器经本机进程间通道连接用户选定的 komapedit 实例。协议依据见 [MCP 传输规范](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports)和 [MCP 工具规范](https://modelcontextprotocol.io/specification/2025-11-25/server/tools)。
2. 提供查询当前地图和元素、验证编辑批次、应用、保存和还原工具。查询读取已发布的工作副本。验证、应用、保存和还原请求转为类型化命令，与 GUI 请求在同一队列串行执行，并核对当前地图及工作副本版本。过期请求返回当前状态供客户端重新查询。
3. 应用成功后更新共享工作副本、刷新视图并记录撤销历史。显式保存等待前序编辑通过校验，核对磁盘基线后提交。断开连接时保留 GUI 中的待保存修改。
4. 使用 MCP 客户端完成查询、验证、应用、查看界面变化和保存的完整流程。覆盖界面与 MCP 交替编辑、切图后的过期请求、保存失败和重新连接。

**完成条件**

AI 客户端和 GUI 可交替操作同一工作副本。应用在界面可见，保存和还原遵循共享编辑队列的顺序。

## S25 自定义工作区

**主要位置：** 配置读写、布局序列化、窗口显隐与主菜单。

1. 确定工作区包含的布局、窗口显隐和视图参数范围，以及启动恢复规则。
2. 按现有配置分工确定具名预设的存储结构：应用偏好使用 `settings/settings.ini`，最近打开与地图历史使用 `settings/history.ini`，Dear ImGui 布局使用 `settings/imgui.ini`。
3. 基于现有布局内存序列化实现创建、重命名、删除、切换和启动恢复，保持当前地图、场景及资源列表草稿。
4. 扩展设置持久化验证，检查连续切换与重启；手动检查六种语言的稳定窗口标识、不同缩放比例和多显示器布局。

**完成条件：** 两套不同布局可保存、切换并在重启后恢复；界面状态符合约定范围，编辑数据和草稿持续保留。

## 阶段通用验收与进度维护

1. BVE 文件读取、编辑、创建、生成或写回实施前，按[格式合规流程](../.agents/skills/komapedit-bve-format-compliance/SKILL.md)核对有效的官方页面缓存，并为本阶段建立合规矩阵。工程规则逐项记录规范版本、适用条件和独立计算样例。
2. 公共类型化接口增加字段或对象时，明确版本和结构大小，同步组件、调用方、所有权说明与契约验证。
3. 自 [S9](#s9) 起，地图编辑通过后台队列更新工作副本。显式保存提交磁盘，还原丢弃待保存修改，重载读取磁盘。验收覆盖编码、字节序标记、换行、注释、引用、解析顺序、连续编辑、源哈希和非目标语义。Scenario 和外部文档按各自的显式保存契约验收。
4. 用户可见文本同步六种界面语言；表格、标记和场景在输入改变时更新缓存。2D 编辑、三维操作、工作区和新向导完成对应的实际界面与视觉验收。
5. 按[调试与无界面验证流程](../.agents/skills/komapedit-debug-headless-validation/SKILL.md)选择证据：正常代码实现先用 `build_dev.bat` 构建，再运行相关契约和显式无界面验证。新增行为补充针对性验证；发布构建用于发行打包、依赖布局或优化相关任务。
6. 每项完成后同步 [TODO.md](../TODO.md)、本计划与[完成事项归档](TODO_done.md)，按文档所有权更新使用说明和开发指南。记录已完成的自动验证与手动验收；有限子集按自己的交付范围记录。
