# komapedit 用户手册

本手册介绍 komapedit 的界面、预览和编辑操作，并提供导出 CSV 数据的格式说明。

项目简介、支持的 BVE 地图语法及安装与启动说明，请参阅[中文 README](README_zhcn.md)。

## 报告问题

使用 komapedit 时遇到崩溃、界面显示异常、地图元素特性与BVE中不一致、编辑或保存失败等问题，可通过 `帮助 -> 报告问题` 打开问题提交页面，也可直接访问项目的 [GitHub Issues](https://github.com/NewSapporoNingyo/komapedit/issues)。

提交前请先搜索是否已有相同问题；若已有报告，可在其中补充信息。新问题请登录 GitHub 后创建 Issue，标题简要说明出问题的功能和现象，例如“打开某地图后，加载 3D 场景预览时崩溃”。

### 需要提供的信息

- **操作系统与硬件**：Windows 版本、内部版本号及系统架构。可通过 `Win+R` 输入 `winver` 查看 Windows 版本与内部版本号。涉及 3D 显示或性能问题时，请补充 CPU、内存容量、显卡型号及显卡驱动版本。
- **程序版本**：使用的 komapedit 发布版本或 Git 提交号，以及程序获取来源；如果使用自行编译的版本，请补充 Debug/Release 构建类型和编译器版本。无法确定版本时，请注明下载或构建日期。
- **问题现象与预期结果**：分别说明希望程序怎样工作、实际发生了什么，并保留错误提示的完整文字。若涉及卡顿，请说明发生在哪个操作阶段及大致持续时间。
- **复现步骤**：从启动程序、打开文件开始，按顺序列出操作，写明相关菜单、参数、设置，以及是否点击了“应用”或“保存”。注明问题是每次必现还是偶发；若仅在特定位置或元素上发生，请提供里程、元素 key 或源文件位置。
- **控制台日志**：提供从加载相关文件到问题发生后的完整日志，获取方法见下文。日志较长时可保存为 `.txt` 附件。
- **复现文件**：如果问题只在特定地图上出现，请尽量提供能复现问题的地图文件。<br>
若问题发生在不公开的地图上，请尽量提供能复现问题的最小文件集，不一定需要提供完整地图。可通过邮件向开发者发送必要的文件（地图、Include 子地图、资源列表、模型或贴图等），并保留相对目录关系。<br>
若地图是公开的BVE地图，请提供此地图的下载链接，以方便项目开发者复现问题。<br>
编辑或保存问题如有修改前后的文件，也请一并提供并注明差异。
- **截图或录屏**：涉及界面、2D/3D 显示或操作顺序的问题，请附上能展示现象的截图或短录屏；同时保留文字说明和日志，便于检索和分析。

上传前请检查日志、截图和附件中的个人路径等信息；若直接在GitHub Issues中提供全部信息，复现文件应使用可公开分享的内容，并尽量保留触发问题所需的条件。

### 获取控制台日志

1. 从 `辅助信息 -> 控制台窗口` 打开控制台。
2. 在可复现的情况下，使用测试文件或文件副本重复触发问题，保留文件加载到问题发生后的日志；复制前不要点击“清除”。
3. 点击控制台的“复制”，将全部日志复制到剪贴板。
4. 将日志粘贴到 Issue 的代码块中，或保存为 UTF-8 文本文件后作为附件上传。

若程序已经崩溃、无响应或无法启动，导致无法复制控制台日志，请在报告中注明，并提供最后一次操作、错误对话框或截图。若能取得 Windows 事件查看器中的相关应用程序错误，也可一并附上。

## 使用方法

本节介绍界面、预览和编辑操作。查看地图可直接使用各类视图；修改文件前，请阅读第 10 节并备份地图。

### 1. 主界面

主界面由以下部分组成：

- **顶部菜单**：打开文件、切换窗口、调整 2D/3D 设置以及打开帮助页面。
- **工具栏**：提供打开、重新加载、编辑、保存、车站跳转和里程跳转等常用操作。
- **中央工作区**：显示 2D 视图、文件结构图、文本预览、3D 模型预览和 3D 场景预览。多个窗口可以作为标签页叠放，也可以拖动到其它位置停靠。
- **地图信息表格**：通常停靠在右侧，用于查看车站、布景、信号、音效和其它地图元素。
- **控制台窗口**：通常位于右下方，显示地图加载、模型加载、编辑和保存过程中的详细信息。
- **底部状态栏**：显示当前操作状态以及错误、警告数量。

窗口关闭后，可从 `地图信息列表`、`2D视图`、`3D视图` 或 `辅助信息` 菜单重新打开。窗口显示状态和停靠布局自动保存。

### 2. 顶部菜单

#### 文件

- `新建...`：打开“新建文件向导”。可新建地图、Scenario 或资源列表文件，详细说明见第 10 节。
- `打开...`：选择 `.txt` 或 `.csv` 地图/Scenario 文件。也可使用工具栏中的“打开”。
- `最近打开的地图`：重新打开最近使用的地图，或清除历史记录。
- `重新加载`：重新读取当前地图、刷新已启动的 3D 场景，并重新加载当前单模型预览。快捷键为 `F5`。存在未保存更改时，程序会先要求确认。
- `导出 CSV...`：选择目录，导出当前自轨道和各条他轨道的几何数据，并覆盖目录中的同名文件。不同轨道生成相同输出文件名时停止导出，详情可在控制台查看。CSV 字段说明见后文附录。
- `退出`：关闭程序。存在未保存更改时，可选择保存、放弃或取消退出。

打开 `BveTs Scenario 2.00` 格式的文件后，可查看 Scenario 内容并加载其中的地图：

- 从 `地图信息列表` 的“其它”分组打开 `Scenario 文件`，查看字段、Route/Vehicle 路径和权重。启用编辑模式后，直接在输入框中修改；标题、作者、说明等文字字段及 Image 路径也可补填。
- 右键路径可选择文件或打开目录。已有 Route/Vehicle 字段支持新增、删除和上下移动候选，每个字段至少保留一个候选。新增候选默认权重为 `1`，需填写路径；权重须大于 `0`。
- 只有一个有效 Route 时直接加载该地图；有多个候选时由用户选择。
- Route 缺失、无效或取消选择时，仍可查看和编辑 Scenario。Vehicle 在此显示引用路径和权重。
- Scenario 修改通过工具栏“保存”或 `Ctrl+Shift+S` 直接写入文件。地图和 Scenario 同时有修改时先保存地图；若 Route 候选路径或顺序也已改变，程序会提示再次保存 Scenario。保存后使用“重新加载”载入所选地图。
- 最近文件、背景对齐历史和重新加载均以 Scenario 文件为入口。重新加载时会重新读取 Scenario、按需选择 Route 并刷新模型；“重新加载线形”会尽量保留场景模型和相机。

#### 选项

- `用户界面设置...`：调整文字大小、界面组件大小和主题色。
- `2D画布设置 -> 画布元素尺寸`：调整标记大小、自轨道/他轨道线宽、图表标线和网格线宽。
- `2D画布设置 -> 绘图范围...`：输入最小、最大里程并点击“应用”，调整 2D 显示范围。“重置”填回默认范围，再点击“应用”生效。
- `2D画布设置 -> 控制点间隔...`：调整轨道几何的采样范围和间隔，点击“应用”重新生成几何数据。较小间隔可增加曲线采样密度；CSV 导出使用重新生成的数据。
- `3D画布设置`：调整场景绘制距离、编辑组件尺寸、相机速度、雾效果、地图绘制距离、自动加载和性能警告。

文字、组件尺寸、配色和 3D 显示参数支持即时预览；点击“确定”保存设置，“取消”恢复打开对话框前的值。

#### 地图信息列表

按车站、布景、轨道几何、信号、音效、效果和其它内容分组打开各类表格。表格的具体功能见第 6 节。

#### 2D视图

- 显示或隐藏整个 2D 视图窗口、纵断面图和曲线半径图。
- 显示或隐藏坡度变化点、坡度值和纵断面中的他轨道。
- 导入、显示、调整背景图，或使用两个车站位置对齐背景图。调整项包括位置、尺寸、旋转角度和亮度。

#### 3D视图

- `布景模型预览`：显示或隐藏单个模型的预览窗口。
- `3D场景预览`：显示或隐藏整张地图的场景预览窗口。

#### 辅助信息

- 分组控制 2D/3D 中的车站、轨道几何、信号、音效和效果标记。
- “轨距设定点”“外轨超高中心设定点”“缓和曲线参数设定点”分别显示 `CG`、`CC`、`CF` 标记；“闭塞标记”显示绿色 `S` 标记及信号索引。这四项默认关闭，可按需开启。
- “先行列车通过点”显示 `PreTrain.Pass` 标记，启用编辑模式后可右键修改里程、通过时间或删除。
- “自轨道标记”和“平面图上显示当前位置”控制 3D 场景与 2D 平面图之间的辅助显示。
- `其它 -> 自定义消息`、`文件结构图`、`文本预览`、`控制台窗口` 用于打开对应工具窗口。

平面图中的信号机标记由“地图信号”表格的“显示”勾选框控制。他列车路径在“他列车”表格中逐项控制。

#### 语言与帮助

- `语言`：在简体中文、英语和日语之间切换。
- `帮助`：打开在线文档、问题反馈页面或“关于”窗口。

### 3. 工具栏

- **打开**：选择并打开地图或 Scenario 文件。
- **重新加载**：重新读取地图、刷新已启动的 3D 场景，并重载当前单模型预览；效果与 `F5` 相同。
- **重新加载线形**：重新读取地图，更新线形和放置数据，并尽量复用已加载的 3D 场景模型、保留相机位置，适合外部修改线路代码后刷新预览。
- **编辑模式**：启用或关闭编辑功能。首次启用会显示风险提示。
- **添加地图元素**：启用编辑模式并完成编辑数据加载后，打开“新建地图元素向导”。
- **保存**：把已应用的地图修改和 Scenario 修改写入源文件，快捷键为 `Ctrl+Shift+S`。资源列表和自定义消息的草稿须先在各自表格中应用。
- **撤销**：确认后，放弃全部待保存修改、资源列表及自定义消息草稿和 Scenario 修改，将内存工作副本恢复到上次保存时的状态。
- **车站跳转**：从下拉列表选择车站，同时定位 2D 视图；3D 场景已启动时也会移动场景相机。
- **跳转到里程(m)**：输入数字后点击“跳转”，或在输入框中按 `Enter`。3D 场景已启动时也会同步移动相机。

全局快捷键为 `F5`（重新加载）和 `Ctrl+Shift+S`（保存）。2D、3D 画布操作分别见第 5、9 节。

### 4. 状态栏与控制台

#### 底部状态栏

- 左侧的 `Err` 和 `Warn` 显示错误、警告数量。点击该区域可查看错误和警告摘要。
- 右侧状态文字显示“加载中”“就绪”“正在应用更改”“已保存”等当前状态；耗时操作完成后还会显示用时。

#### 控制台窗口

控制台显示完整的加载、解析、模型和编辑日志。遇到地图无法打开、模型缺失或保存失败时，应先查看这里。

应用、保存和删除的总用时显示在状态栏，分阶段耗时记录在控制台的 `edit timing:` 日志中。

- **清除**：清空日志，同时把错误和警告计数归零。
- **复制**：把全部日志复制到剪贴板，便于反馈问题。
- 日志停留在底部时自动跟随新内容；向上滚动可停留查看历史日志。

### 5. 2D 画布

2D 视图上方可选择“移动”或“测量”模式。网格设为“固定”时保持在屏幕上，设为“可移动”时跟随地图平移、缩放和旋转，设为“无”时隐藏。上下拖动平面图与下方图表之间的分隔条可调整高度；左右拖动两张图表之间的分隔条可调整宽度。

#### 平面图：移动模式

| 操作 | 功能 |
| --- | --- |
| 按住鼠标左键拖动 | 平移平面图 |
| 滚动鼠标滚轮 | 缩放平面图 |
| `Shift` + 鼠标滚轮 | 每次旋转平面图 5° |
| `Ctrl` + 鼠标左键拖动 | 围绕画布中心连续旋转 |
| 双击鼠标左键 | 恢复为适合窗口的完整范围 |
| 右键单击标记 | 打开定位、查找或预览菜单；编辑模式下还会显示“属性/编辑”和“删除” |

触控操作中，单指拖动用于平移，双指手势可同时平移、缩放和旋转；长按标记相当于右键单击。

#### 纵断面图与曲线半径图

纵断面图显示里程与标高；曲线半径图区分左、右曲线并标注半径。鼠标左键拖动可平移，滚轮缩放横向里程范围；“移动”模式下双击可恢复视图范围。触控时横向双指缩放调整里程范围，纵断面图还支持纵向双指缩放标高轴。

#### 平面图与图表：测量模式

- 把鼠标移到轨道附近，可实时查看里程、标高、坡度、曲线半径和当前限速。
- 在平面图、纵断面图或曲线半径图中双击，可把三个视图的测量位置同步到该里程。

#### 标记、定位与编辑

- 通过 `辅助信息` 菜单选择要显示的标记。
- 开启“曲线半径”后，`Curve.Interpolate` 端点以绿色标记显示，旁边标注求值后的有符号半径；省略半径时显示继承值。
- 右键标记可定位到对应表格；有 3D 对象的项目还可定位到 3D 场景。
- 启用编辑模式后，可右键受支持的标记进行“属性/编辑”或“删除”。自轨道曲线/坡度及他轨道的编辑控制点在此模式下显示；`Curve.Interpolate` 和 `CG`/`CC`/`CF` 标记按各自开关显示。
- 纵断面图和曲线半径图中，已配对的曲线/坡度变化点提供编辑菜单。

#### 背景图

在 `2D视图` 菜单的“背景图”分组点击“导入”选择图片。“显示”控制图片可见性，“调整”可设置位置、宽高、旋转角度和亮度。

地图至少有两个车站时，可用“按车站对齐”完成对齐：

1. 选择 `Station 1`，点击“在平面图选点”，在背景图上双击该站的位置。
2. 选择另一座车站作为 `Station 2`，以同样方式选取位置。
3. 点击“应用”或“确定”，计算图片的位置、比例和旋转角度。

背景图路径和对齐参数按当前地图或 Scenario 入口记录，重新打开时恢复。

### 6. 地图信息表格

#### 通用操作

- 在 `地图信息列表` 中打开所需表格。在提供定位菜单的里程单元格上右键，可定位到平面图或已启动的 3D 场景。
- 右键源文件或资源文件路径，可打开其所在目录。悬停路径通常会显示原始参数和解析后的绝对路径。
- 布景模型、信号现示、音效文件和 3D 音效文件表格可展开“查找”，选择部分或完全匹配，输入后按 `Enter` 或点击“查找”，用上下箭头切换结果。英文匹配忽略大小写。
- “查找未使用…”高亮当前地图中未被引用的定义。布景检查包含放置、连续布景、背景、信号和他列车引用；普通音效检查包含车站到达/出发音效，并计入当前列表草稿。
- 在地图放置行中右键资源 key，可跳到对应的布景模型、信号现示或音效定义。
- 启用编辑模式后，右键可编辑元素的单元格可选择“属性/编辑”或“删除”；部分表格支持双击打开“属性/编辑”。

#### 车站与布景

- **车站列表**：上半部分显示 `Station.Put` 的停车里程、开门方向和前后停车容差，通过右键“属性/编辑”修改；下半部分显示 `Station.Load` 载入的站名、到发时刻、停车时间和音效等定义，采用行内编辑。
- **地图布景**：显示 `Structure.Put` 和 `Structure.Put0`。可定位到平面图、3D 场景或对应模型定义。
- **地图布景（PutBetween）**：显示 `Structure.PutBetween`，用于查看两条轨道之间的变形布景。
- **布景模型**：显示 structureKey 和模型路径。右键 key 可预览模型或把该 key 填入已打开且类型匹配的新建元素向导。
- **连续布景**：将同名 `Repeater.Begin`/`Begin0`/`End` 显示为区间，可定位起点、终点或变化点。属性窗口用于调整各段参数、模型顺序和结束里程，具体操作见第 10 节。
- **他列车**：显示他列车定义、停止位置和只读的 `Train.Enable` 时间。可逐条控制路径显示，并把停止位置定位到平面图。

#### 轨道几何、信号与闭塞

- **其他轨道**：通过“显示”或“全选”控制 2D/3D 轨道显示，起止里程和颜色用于调整 2D 视图。编辑模式下可右键 `Key` 重命名同名 `Track[...]` 语句；布景、信号和 Repeater 中的轨道引用须另行修改。
- **轨道变位、粘着特性变化点、限速点**：显示相应变化位置，并可定位到 2D/3D。限速 Begin 和 End 可以独立存在；End 只编辑里程。
- **信号现示**：显示信号现示定义和引用的布景 key，可反查布景模型。
- **地图信号**：显示 `Signal.Put` 的位置和参数。“显示”勾选框控制该信号在平面图中的标记。
- **闭塞**：显示 `Section.Begin`/`BeginNew` 的信号索引，以及 `Section.SetSpeedLimit`/`Signal.SpeedLimit` 的现示限速。通过“属性/编辑”中的 `+`、`-` 和上下箭头增删、排序参数；现示限速可用 `null` 表示无速度限制。表格最多显示 508 个参数，完整列表可在属性窗口查看。
- **应答器**：显示并定位 `Beacon.Put`。
- **变量**：按不区分大小写的变量名分组显示全部赋值。悬停可查看原表达式；该表只读。

#### 音效与效果

- **音效文件、3D音效文件**：显示音效 key、文件路径和缓冲区数量，并可打开文件所在目录或把 key 填入匹配的新建元素向导。
- **地图音效、地图3D音效、走行音变化点、轮缘摩擦音效变化点、道岔音效播放点**：显示并定位播放点或变化点。
- **背景变化点、驾驶台亮度变化点、雾效果变化点、旧式雾效果变化点、绘制距离变化点**：显示并定位对应效果。
- **光照**：分别显示 `Light.Ambient`、`Light.Diffuse` 的 RGB 和 `Light.Direction` 的 pitch/yaw。编辑模式下直接修改参数并点击本窗口“应用”，再用工具栏“保存”；缺少的项目可点击“新建”，已有项目可点击“删除”。
- **Scenario 文件**：显示已打开的 Scenario 字段及候选。编辑和保存方式见第 2 节。

#### 资源列表的行内编辑

开启编辑模式后，车站定义、布景模型、信号现示、音效文件和 3D 音效文件使用以下行内编辑方式：

- 双击可编辑单元格开始输入，按 `Enter` 或离开单元格暂存草稿；右键可在上方/下方新增行、上移/下移整行、清空单元格或删除整行。资源文件路径单元格还提供“选择文件”。
- 空列表可通过“新增行”添加第一条记录。
- “选择文件”会尽可能保存相对路径；无法生成相对路径时使用绝对路径。
- 信号现示主行与眩光行作为整体移动或删除。新增主行默认为 6 个字段，可通过“新增眩光”添加眩光行。
- 点击表格中的“应用”更新内存预览；各表格草稿全部应用后，点击工具栏“保存”写入文件。

信号现示列表按各 CSV 行的实际字段数显示，保留尾部空字段。斜线表示该行没有对应字段，已有空白字段可直接编辑。表格最多显示 509 个结构键列，超出部分保留在源数据和草稿中，并显示提示。

- 右键 CSV 单元格，可在当前行最右侧新增一格、删除末尾空白格或删除最后一格。主行与眩光行可有不同字段数。
- “对齐所有列”将各行补齐至最大字段数；“在右侧新增列”和“删除最右侧列”分别为各行增减一格；“删除全部右侧空白”裁去各行末尾空字段。
- 各行至少保留首个 CSV 字段和一个可为空的结构键字段。眩光行的首字段固定为空，整行通过“删除眩光”移除。
- 删除非空末格前会要求确认。批量列操作也包含显示上限之外的字段。

已有的多条连续眩光行会合并显示，编辑时须保持合并后的字段总数；移动或“删除眩光”作用于整个眩光组。完成单元格或列操作后，统一按“应用”→“保存”提交。

每张地图可载入各类资源列表各一份。尚未载入时，点击表格中央的“新建或导入文件”；替换时，右键顶部“文件路径”，选择“更换文件...”。若该列表有未应用或未保存的修改，程序会确认后丢弃该列表的修改。

komapedit 兼容 Station List 0.04+、Structure List 1.00+、Signal Aspects List 和 Sound List 2.00+。普通音效与 3D 音效使用同一种 Sound List 格式。资源列表的标准注释符为 `#`，komapedit 还兼容 CSV 双引号外的 `//` 注释。

### 7. 文件结构图与文本预览

从 `辅助信息 -> 其它 -> 文件结构图` 打开该窗口。入口地图位于最左侧，右侧按层级显示它所 Include 的子地图；悬停节点可查看 Include 参数和绝对路径。

#### 查看文件

- 右键有效节点，选择“预览文本”，可在只读文本预览窗口中查看源码和行号。
- “属性/编辑”窗口中的源文件名也提供“预览文本”。地图和资源列表的文本预览会随“应用”刷新，可用于检查保存前的源码结果。
- “在文件资源管理器中打开”可打开目标目录；目录不存在时在控制台报错。
- 缺失或无效的 Include 目标显示为红色节点，其文本预览、导入和新建子地图操作禁用。

#### 编辑 Include

以下操作要求编辑模式：

- **更换文件...**：选择新的 `.txt`/`.csv` 子地图，改写上级文件中的 Include 路径。优先使用相对路径，失败时使用绝对路径。
- **解除引用**：删除上级文件中的 Include 语句。如果后续语句仍依赖该子地图提供的内容，操作会被阻止。
- **导入子地图...**：选择已有 BVE 地图，并在当前节点代表的源码文件中暂存新的 Include。
- **新建子地图...**：在新文件路径创建 UTF-8 无 BOM、CRLF、文件头为 `BveTs Map 2.02:utf-8` 的空白子地图，并暂存 Include。

新增 Include 放在首个本地距离语句之前的最后一个 Include 之后；没有此前 Include 时，放在首个距离语句之前；两者均无则追加到文件末尾。修改会立即更新预览，点击“保存”后写入父地图。

在 komapedit 中，各 Map 文件的 `distance` 从 `0` 开始，Include 结束后恢复父文件里程，普通 `$变量` 共享。相对父地图放置子地图时，可先写 `$dis=distance;`，再在子地图内用 `$dis+偏移量;` 设置里程。

### 8. 3D 模型预览

从 `3D视图 -> 布景模型预览` 打开窗口，再从“布景模型列表”右键某个 structureKey，选择“预览模型”。

- **模型列表**：打开布景模型列表。
- **重新加载**：重新读取当前模型及其材质、纹理。
- **清除**：从预览窗口移除当前模型。
- **背景颜色**：选择任意 RGB 颜色，或使用白、黑、灰、蓝、绿快捷颜色。
- 在画布中按住鼠标左键拖动可旋转模型；滚动鼠标滚轮可缩放。

模型或纹理加载失败的详情可在控制台查看。

### 9. 3D 场景预览

从 `3D视图 -> 3D场景预览` 打开窗口，点击“启动3D场景预览”。也可在 `选项 -> 3D画布设置` 中开启“打开地图时自动加载场景预览”（默认关闭），随打开或重新加载地图自动启动。

窗口顶部提供“启动3D场景预览”“重新加载（模型）”和“关闭”：

- “重新加载（模型）”重新读取场景使用的模型，保留当前地图和相机位置。
- “关闭”释放当前场景；窗口本身仍可保持打开。

#### 移动模式与快捷键

把鼠标停在 3D 画布上时可使用以下操作：

键盘移动在“移动”“选择”和“里程选择”三种模式中都可用；鼠标左键拖动转动视角只在“移动”模式中可用。

| 操作 | 功能 |
| --- | --- |
| 鼠标左键拖动 | 在“移动”模式中转动视角 |
| `W` / `S` | 沿线路向前 / 向后移动 |
| `A` / `D` | 向左 / 向右移动 |
| `R` / `F` | 向上 / 向下移动 |
| 按住 `Ctrl` | 加快上述键盘移动速度 |
| `X` | 在当前里程恢复到自轨道中心上方的默认相机姿态 |

相机速度可在“3D画布设置”中调整，也可通过工具栏跳转到车站或指定里程。相机最远可后退至自轨道起点前 100 m。开启“平面图上显示当前位置”后，2D 平面图同步显示相机位置。

#### 选择模式

- 把鼠标移到场景对象或标记上可高亮目标。
- 右键对象或标记可定位到对应的地图信息表格；连续布景还可跳到起点或结束/变化位置。
- 右键信号机，选择“切换信号现示”，可按索引和布景 key 切换该对象的预览模型。
- 编辑模式下，同一菜单还会提供“属性/编辑”和删除操作。编辑操纵器见第 10 节。

#### 里程选择模式

- 鼠标附近会显示自轨道平面上最近的整米横断面和里程标签。
- 编辑模式下，右键该位置可选择“在当前里程新建地图元素”，向导会自动填写 distance。

#### 场景叠加信息与设置

画布显示相机位置、当前曲线半径/超高、坡度、限速、闭塞信号速度和下一站信息。`Curve.Interpolate` 区间显示两端的半径、超高和曲线方向；两端半径均为零时显示“直线”。底部显示场景块、实例、模型加载数量和帧率。

FPS 显示场景画布的刷新频率，空闲时保留上次统计值。

在 `选项 -> 3D画布设置` 中可调整：

- **绘制距离**：控制相机前方的场景范围；开启“绘制距离根据地图语句调整”后，结合 `DrawDistance.Change` 限制显示范围。
- **雾效果**：切换地图中的雾预览。
- **编辑用组件尺寸、相机移动速度**：调整操纵器大小和键盘移动速度。
- **性能警告**：按当前绘制的实例数量着色提示，超过“警告标准”为黄色，超过“严重警告标准”为红色。

相关标记的显示状态与 `辅助信息` 菜单同步。

雾预览支持 `Fog.Interpolate`/`Fog.Set` 指数雾，以及兼容语句 `Legacy.Fog` 的线性雾。同类雾节点间渐变，异类节点间在后一节点切换。`Legacy.Fog` 的 start/end 使用相机深度距离（米），RGB 为 0–255；零里程设置立即生效，前后均为线性雾时，后续设置在 25 米内过渡。两类雾均可从表格或标记编辑，并在向导的“效果”分类中新建。

#### 场景标牌

通过 `辅助信息` 控制标牌显示。开启“曲线半径”后，`Curve.Interpolate` 插值点显示半径、超高和曲线方向；半径为零时显示 `Intpl. 0`。标牌支持拾取、高亮，以及编辑模式下的右键编辑和删除。

### 10. 编辑、新建与保存

#### 开始编辑前

首次启用工具栏“编辑模式”时会显示提示，可勾选“不再显示”并确认。

开启后等待编辑数据加载完成，再进行修改。在属性窗口、光照窗口或向导中填写的内容，先点击“应用”再离开。关闭编辑模式、打开其它文档、重新加载或退出程序时，程序会提示处理待保存更改。

#### 草稿、应用、保存与撤销

地图与资源列表的编辑流程如下：

1. **修改草稿**：在“属性/编辑”、资源列表或向导中输入内容；部分对象可实时预览。
2. **应用到预览**：点击窗口中的“应用”，验证并重新解析内存工作副本，刷新 2D、表格和 3D 预览。
3. **保存到磁盘**：点击工具栏“保存”或按 `Ctrl+Shift+S`，将全部已应用更改写入对应的地图、Include 或资源列表文件。

资源列表和自定义消息的草稿须全部应用后才能保存；Scenario 输入框中的修改直接由工具栏“保存”提交。工具栏“撤销”恢复上次保存时的内存状态；要读取外部编辑器写入的内容，使用“重新加载”。

保存前会重新解析并核对修改结果，保留原文件编码、BOM 和换行格式。新文本超出原编码范围，或文件已被其它程序修改时，程序会阻止保存并提示原因。

#### 编辑或删除已有地图元素

1. 在表格、2D 标记或 3D 标记上右键，选择“属性/编辑”。
2. 在窗口中确认源文件、源码位置和原始语句，再修改字段。
3. 点击“应用”刷新内存预览。
4. 检查 2D、表格和 3D 结果；确认无误后使用工具栏“保存”。

支持编辑车站、布景、信号、应答器、连续布景、闭塞、限速、曲线与坡度、他轨道、轨道变位、音效、背景、粘着、驾驶台亮度、雾、光照参数、绘制距离和先行列车通过点等。右键“删除”会将删除操作应用到预览，保存时写入源文件。

`Structure.Put`/`Put0` 和 `Repeater.Begin`/`Begin0` 可通过“添加坐标偏移”或“去除坐标偏移”切换形式；清除非零偏移前需确认。短式 `Signal.Put` 在编辑 Z、旋转、倾斜或跨度前，需确认转换为完整形式。

#### 连续布景的分段编辑

- 打开 Repeater 的“属性/编辑”，用“上一个”“下一个”切换同名连续布景的变化段。
- 用结构键列表旁的 `+`、`-` 和上下箭头增删、排序循环放置的模型。
- “插入变化点”打开预填当前参数的向导；填写新里程和参数后应用。末段尚无 End 时，可用“添加结束位置”补上。
- 多段区间的删除菜单提供“全部删除”“删除对应变化点”“修剪至变化点”和“从变化点开始”，分别处理整条链、单个变化点、后续区段或前段。操作应用到预览后，再统一保存。

#### 在 3D 场景中实时调整

打开“属性/编辑”后，可拖动受支持对象的操纵器调整草稿，再按上述流程应用、保存。

- `Structure.Put`、完整式 `Signal.Put` 和 `Repeater.Begin` 可使用 X/Y/Z 轴调整坐标。
- `Sound3D[soundKey].Put(x, y)` 的 X/Y 轴以 0.001 m 调整相对位置，Z 轴以整米调整里程。
- `Structure.Put0` 和 `Repeater.Begin0` 使用 Z 轴调整整米里程；添加坐标偏移后可使用完整坐标操纵器。
- 带显式 End 的 Repeater 可在结束位置通过 Z 轴调整整米结束里程。
- `Structure.PutBetween` 使用 Z 轴调整整米里程，并实时重新计算变形后的模型。

#### 新建地图元素向导

从工具栏“添加地图元素”打开向导，或在 3D“里程选择”模式中右键当前里程打开。选择目标源文件、模板并填写参数；已加载的地图源文件（包括空白或无距离语句的文件）均可作为目标。

新建或移动元素时，程序会自动安排距离语句并保留其他语句与注释。需要手动定位时，在文本预览中选中高亮的语句边界，点击“确定”继续；需要指定距离表达式时，在提示框中填写源字符串并点击“应用”。

向导按以下类别提供当前支持的元素：

- **布景**：`Structure.Put`、`Put0`、`PutBetween`，以及 `Repeater.Begin`/`Begin0`/`End`。
- **车站**：`Station.Put`。
- **轨道几何**：曲线、坡度、轨距、曲线中心与插值函数、轨道变位和粘着变化。
- **其他轨道**：位置、X/Y 插值和超高相关的 `Track.*` 语句。
- **信号**：信号、限速、闭塞、信号速度、应答器和 `PreTrain.Pass` 先行列车通过点。
- **音效**：地图音效、3D 音源、走行音、轮缘摩擦音和道岔音。
- **效果**：背景、驾驶台亮度、雾、光照参数和绘制距离。
- **其它**：自定义消息，作为注释放在地图文件头下方。

“应用”新建元素并刷新预览；“应用并编辑”还会关闭向导，打开新元素的“属性/编辑”窗口或“自定义消息”标签页。Repeater 的变化点向导使用“应用”。

各模板的填写要点：

- **Repeater**：可添加 Begin、End 或两者；成对添加时，结束里程须大于或等于起始里程，同名成对区间须避免重叠。区间内的参数变化使用“插入变化点”。
- **曲线与坡度**：可分别添加起点、终点，或成对创建。曲线起点可选 `Curve.Begin` 或 `Curve.Change`，终点使用 `Curve.End`；坡度使用 `Gradient.Begin`/`End`。Begin/End 可配套创建缓和段起点，`Curve.Change` 直接修改半径。
- **曲线插值点**：`Curve.Interpolate` 的 distance 必填，radius 与 cant 默认均为 `0`。可取消 cant 生成单参数形式，或取消 radius 生成无参数形式。
- **其他轨道**：可选尾参数须连续启用，例如填写 `radiusV` 前须包含 `radiusH`。新的 trackKey 会创建他轨道，数值键与带引号的字符串键分别处理。
- **先行列车通过点**：`passTime` 可填写 `hh:mm:ss`，或从午夜起算的秒数；悬停输入框可查看格式提示。
- **光照**：向导在里程 `0` 新建，RGB 填写 `0`–`1`；每类光照语句在整个地图（含 Include）中各设一条。

#### 自定义消息（Message from Creator）

在新建地图元素向导中选择“其它 → 自定义消息”，选定地图源文件并填写单行消息。应用、保存后，消息以以下注释格式写在文件头空行之后；已有消息时追加到消息块末尾：

```plaintext
BveTs Map 2.02

//--kme--message-from-creator:"content"
```

消息使用普通 BVE `//` 注释保存，内容按原文处理，保留空格、引号和反斜杠。可填写空消息；内容须为单行且无 NUL 字符。

打开地图或 Scenario 时，会展示主地图及已加载 Include 中的消息，多条消息可翻页查看。重复引用同一文件时，同一条消息仅展示一次。勾选“下次不再显示”并确认后，程序会按主地图记住该选择。

通过“辅助信息 → 其它 → 自定义消息”可随时查看源文件、行号与内容。输入关键字并按 `Enter` 或点击“查找”，可查找源文件或消息内容，用上下箭头切换结果。

开启编辑模式后，双击内容单元格编辑，按 `Enter` 或离开单元格暂存草稿，`Esc` 取消当前输入；右键“删除整行”暂存删除操作。完成后点击页内“应用”，再通过工具栏“保存”。

#### 新建文件向导

从 `文件 -> 新建...` 打开，可创建 Map、Scenario、Structure List、Signal Aspects List、Sound List、Sound3D 使用的 Sound List 和 Station List。

1. 选择文件类型，输入不含后缀的文件名，选择 `.txt` 或 `.csv`，再选择目录。
2. 资源列表可通过“导入文件”预填已有 `.txt`/`.csv` 的名称、目录和后缀，再按需修改。
3. 创建 Scenario 时填写所需字段，留空字段会省略。`Route`、`Vehicle` 和 `Image` 可通过“选择文件”填入相对路径。
4. 当前已加载地图时，创建 Map 或资源列表须开启编辑模式，并在“在以下文件中引用”确认目标源文件；尚未加载地图时可直接创建独立文件。
5. 点击“确定”创建或复用文件。创建子地图后，先保存父地图中的引用，再打开子地图；独立地图或 Scenario 可选择“确定并载入”。

已有普通文件会原样复用；新文件使用 UTF-8 和 CRLF，地图与资源列表包含标准文件头，Scenario 按标准字段顺序写入内容。

Scenario 模板提供 `Title`、`Route`、`RouteTitle`、`Vehicle`、`VehicleTitle`、`Author`、`Image`、`Comment` 八个字段。路径字段各接受单一路径，字段值须避开 `#`、`;` 等注释字符；多候选路径与权重可在载入后的“Scenario 文件”标签页编辑。

向导立即创建文件，`include` 或相应 `*.Load` 引用则先应用到地图预览，再由工具栏“保存”写入。每种资源列表可引用一份；更换已引用的文件请使用对应表格顶部“文件路径”的右键菜单。

## 附录：CSV 数据格式

### 自轨道几何 CSV（导出）

通过 `文件 -> 导出 CSV...` 导出当前几何采样结果。文件名格式：

```text
<导出目录名>_owntrack.csv
```

表头：

```csv
#distance,x,y,z,direction,radius,gradient,interpolate_func,cant,center,gauge
```

字段说明：

| 字段             | 说明                                             |
| ---------------- | ------------------------------------------------ |
| distance         | 地图绝对距离，单位 m                             |
| x                | 考虑纵坡投影后的自轨道平面 X 坐标，单位 m       |
| y                | 考虑纵坡投影后的自轨道平面 Y 坐标，单位 m       |
| z                | 标高，单位 m                                    |
| direction        | 轨道方向角，单位 rad                             |
| radius           | 有符号曲线半径，单位 m；正为右曲线，负为左曲线，0 为直线 |
| gradient         | 坡度，单位 ‰                                    |
| interpolate_func | 插值类型，`0` 表示正弦半波缓动，`1` 表示线性缓动 |
| cant             | 超高，单位 m                                    |
| center           | 超高旋转中心的横向坐标，单位 m                  |
| gauge            | 轨距，单位 m                                    |

### 他轨道几何 CSV（导出）

每条他轨道会导出一个 CSV。文件名格式：

```text
<导出目录名>_<trackKey>.csv
```

trackKey 中的 `\ / : * ? " < > |` 会替换为 `_`，空 key 使用 `root`。不同轨道的导出文件名须互不重复。

表头：

```csv
#distance,x,y,z,interpolate_func,cant,center,gauge
```

字段说明：

| 字段             | 说明                                        |
| ---------------- | ------------------------------------------- |
| distance         | 地图绝对距离，单位 m                        |
| x                | 根据投影后的自轨道计算出的他轨道平面 X 坐标，单位 m |
| y                | 根据投影后的自轨道计算出的他轨道平面 Y 坐标，单位 m |
| z                | 他轨道标高，单位 m                         |
| interpolate_func | 超高插值类型，`0` 表示正弦半波缓动，`1` 表示线性缓动 |
| cant             | 超高，单位 m                               |
| center           | 超高旋转中心的横向坐标，单位 m             |
| gauge            | 轨距，单位 m                               |

CSV 导出轨道几何数据，数值固定保留 6 位小数。
