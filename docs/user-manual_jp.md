# komapedit ユーザーマニュアル

このマニュアルでは、komapedit の画面構成、プレビューと編集の操作、出力する CSV データの形式を説明します。

プロジェクトの概要、BVE マップ構文の対応状況、インストールと起動の手順は [README](README_jp.md) を参照してください。

## 不具合の報告

komapedit は、*80% 以上が vibeslop（AI 任せで生成されたコード）* の個人開発プロジェクト。安定性には大規模な商用ソフトウェアとの差があります。

クラッシュ、表示の異常、マップ要素の動作と BVE での動作の違い、編集・保存の失敗などが発生した場合は、`ヘルプ -> 不具合を報告` または [GitHub Issues](https://github.com/NewSapporoNingyo/komapedit/issues) から報告してください。

PRとは異なり、issue はどの言語でも作成可能です。開発者は、有効な issue に対して英訳を提供します。

投稿前に同じ不具合の報告があるか検索し、既存の issue があれば情報を追記します。新しい不具合は GitHub にログインして issue を作成してください。タイトルには「特定のマップを開いた後、3D シーンの読み込み中にクラッシュする」のように、対象機能と症状を簡潔に記載します。

**GitHub Issues はプログラムの不具合報告専用です。操作方法の質問や機能追加の要望は受付対象外です。**

### 報告に含める情報

- **OS とハードウェア**：Windows のバージョン、OS ビルド番号、システムのアーキテクチャ。バージョンとビルド番号は `Win+R` で `winver` を実行すると確認できます。3D 表示や性能の問題では、CPU、メモリ容量、グラフィックスカード、グラフィックスドライバーのバージョンも記載してください。
- **プログラムのバージョン**：komapedit のリリース番号または Git コミットと入手元。自分でビルドした場合は Debug/Release の別とコンパイラーのバージョンも記載します。バージョンが分からない場合は、ダウンロード日またはビルド日を記載してください。
- **実際の動作と期待する動作**：期待していた結果と実際の結果を説明し、エラーメッセージは全文を記載します。遅延やフリーズでは、発生した処理段階とおおよその所要時間も示してください。
- **再現手順**：起動とファイルを開く操作から順番に記載し、使用したメニュー、パラメーター、設定、「適用」「保存」の操作を含めます。毎回発生するか、時々発生するかも記載してください。特定の位置や要素だけで発生する場合は、距離程、要素のキー、ソースファイル内の位置を添えます。
- **コンソールログ**：関連ファイルの読み込みから不具合発生後までのログ全体。取得手順は次項を参照してください。長いログは `.txt` ファイルとして添付できます。
- **再現用ファイル**：特定のマップで発生する場合は、可能な範囲で再現に必要なファイルを提供してください。<br>
未公開のマップでは、再現できる最小限のファイル一式を用意します。マップ、Include 先のサブマップ、リソースリスト、モデル、テクスチャなど、必要なファイルは開発者へメールで送ることもできます。相対的なディレクトリ構成を維持してください。<br>
公開済みの BVE マップでは、開発者が再現できるようダウンロードリンクを記載してください。<br>
編集・保存の問題では、可能であれば変更前後のファイルと差分も添えてください。
- **スクリーンショット・動画**：UI、2D/3D 表示、操作手順に関する問題では、状況が分かる画像や短い動画を添付します。検索や調査に使えるよう、文章による説明とログも記載してください。

アップロード前に、ログ、画像、添付ファイルに個人のパスなどが含まれているか確認してください。GitHub Issues に直接添付する再現用ファイルは、公開可能で、できるだけ発生条件を保ったものを使います。

### コンソールログの取得

1. `補助情報 -> コンソールウィンドウ` からコンソールを開きます。
2. 再現可能な場合は、テスト用ファイルまたはコピーで操作を繰り返し、読み込みから発生後までのログを残します。コピーが終わるまで「クリア」は押さずに進めます。
3. コンソールの「コピー」でログ全体をクリップボードにコピーします。
4. issue のコードブロックに貼り付けるか、UTF-8 のテキストファイルに保存して添付します。

クラッシュ、応答停止、起動失敗などでログをコピーできない場合は、その状況と、最後に行った操作、エラーダイアログ、スクリーンショットを記載してください。Windows イベントビューアーに関連するアプリケーションエラーがあれば、それも添えられます。

## 使い方

画面の操作、プレビュー、編集を説明します。マップの確認には各ビューをそのまま利用できます。ファイルを変更する前に第 10 節を読み、マップをバックアップしてください。

### 1. メイン画面

メイン画面は次の領域で構成されています。

- **上部メニュー**：ファイルを開く、ウィンドウの表示切替、2D/3D 設定、ヘルプの表示。
- **ツールバー**：開く、再読込、編集、保存、駅へのジャンプ、距離程へのジャンプなどの操作。
- **中央の作業領域**：2D ビュー、ファイル構成図、テキストプレビュー、ストラクチャーモデルプレビュー、3D シーンプレビュー。ウィンドウはタブとして重ねたり、別の位置へドラッグしてドッキングしたりできます。
- **マップ情報テーブル**：通常は右側に配置され、停車場、ストラクチャー、信号、サウンドなどの要素を表示します。
- **コンソール**：通常は右下に配置され、マップ・モデルの読み込み、編集、保存の詳細ログを表示します。
- **下部ステータスバー**：現在の処理と、エラー・警告の件数を表示します。

閉じたウィンドウは「マップ情報リスト」「2Dプロット」「3Dビュー」「補助情報」から再表示できます。表示状態とドッキングレイアウトは自動保存されます。

### 2. 上部メニュー

#### ファイル

- **新規作成...**：新規ファイルウィザードを開き、マップ、シナリオ、リソースリストを作成します。詳細は第 10 節を参照してください。
- **開く...**：`.txt` または `.csv` のマップ・シナリオファイルを選択します。ツールバーの「開く」も同じ操作です。
- **最近開いたマップ**：履歴からマップを開くか、履歴を消去します。
- **再読込**：現在のマップを読み直し、起動中の 3D シーンと単体モデルプレビューを更新します。ショートカットは `F5`。未保存の変更がある場合は確認画面を表示します。
- **CSV 出力...**：出力先を選び、自軌道とすべての他軌道の現在の形状データを出力します。同名ファイルは上書きします。異なる軌道の出力ファイル名が重複すると処理を中止するため、コンソールを確認してください。列の説明は付録にあります。
- **終了**：アプリケーションを終了します。未保存の変更がある場合は、保存、破棄、終了のキャンセルを選べます。

`BveTs Scenario 2.00` ファイルを開くと、シナリオ情報の表示とマップの読み込みができます。

- 「マップ情報リスト」の「その他」から「シナリオファイル」を開くと、各項目、Route/Vehicle のパス、重みを表示します。編集を有効にすると入力欄で値を変更でき、タイトル、作者、コメントなどのテキスト項目や Image パスは、元のファイルにない場合も追加できます。
- パスを右クリックすると、ファイルの選択やディレクトリの表示ができます。既存の Route/Vehicle 項目では候補を追加・削除・並べ替えでき、各項目に最低 1 件を残します。追加候補の重みは既定で `1`、パスは必須、重みは `0` より大きい値です。
- 有効な Route が 1 件ならそのマップを読み込み、複数なら候補を選択します。
- Route がない、無効、または選択をキャンセルした場合も、シナリオの表示・編集は可能です。Vehicle は参照先パスと重みを表示します。
- ツールバーの「保存」または `Ctrl+Shift+S` で、シナリオを直接ファイルに保存します。マップにも変更がある場合は、先にマップを保存します。Route 候補のパスや順序も変わっている場合は、シナリオの再保存を案内します。保存後に「再読込」で選択したマップを読み込みます。
- 最近開いたファイル、背景画像の位置合わせ履歴、再読込の入口にはシナリオファイルを使います。再読込ではシナリオを読み直し、必要に応じて Route を選び、モデルも更新します。「線形を再読込」は可能な範囲でシーンモデルとカメラを維持します。

#### オプション

- **UI設定...**：文字サイズ、UI 部品のサイズ、テーマ色を変更します。
- **2Dキャンバス設定 -> キャンバス要素サイズ**：マーカーサイズと、自軌道・他軌道・グラフ補助線・グリッドの線幅を変更します。
- **2Dキャンバス設定 -> 描画範囲...**：最小・最大距離程を入力し、「適用」で 2D の表示範囲を変更します。「リセット」で既定の範囲を入力し、「適用」で反映します。
- **2Dキャンバス設定 -> 制御点間隔...**：軌道形状のサンプリング範囲と間隔を変更し、「適用」でデータを再生成します。間隔を小さくすると曲線のサンプルが密になります。CSV 出力にも再生成後のデータを使います。
- **3Dキャンバス設定**：描画距離、編集部品のサイズ、カメラ速度、霧、マップ指定の描画距離、自動読み込み、パフォーマンス警告を変更します。

文字・部品のサイズ、色、3D 表示パラメーターは変更中にプレビューできます。「OK」で保存し、「キャンセル」でダイアログを開く前の値に戻します。

#### マップ情報リスト

停車場、ストラクチャー、軌道形状、信号、サウンド、効果、その他のグループからテーブルを開きます。各テーブルは第 6 節で説明します。

#### 2Dプロット

- 2D ビュー全体、縦断面図、曲線半径図の表示を切り替えます。
- 縦断面図の勾配変化点、勾配の値、他軌道の表示を切り替えます。
- 背景画像のインポート・表示・調整や、2 駅の位置を使った位置合わせを行います。位置、サイズ、回転、明るさを調整できます。

#### 3Dビュー

- **ストラクチャーモデルプレビュー**：単体モデルのプレビューを表示・非表示にします。
- **3Dシーンプレビュー**：マップ全体のシーンプレビューを表示・非表示にします。

#### 補助情報

- 2D/3D の停車場、軌道形状、信号、サウンド、効果のマーカーをグループ別に切り替えます。
- 軌間設定点、カント中心設定点、緩和曲線関数設定点は、それぞれ `CG`、`CC`、`CF` マーカーを表示します。「閉そくマーカー」は緑色の `S` と信号インデックスを表示します。この 4 種類は既定で非表示です。
- 先行列車の通過点では `PreTrain.Pass` マーカーを表示します。編集を有効にすると、右クリックから距離程・通過時刻の変更や削除ができます。
- 自軌道マーカーと、平面図への現在位置表示は、3D シーンと 2D 平面図で共有する補助表示を切り替えます。
- 「その他」の「カスタムメッセージ」「ファイル構成図」「テキストプレビュー」と、「コンソールウィンドウ」から、対応するウィンドウを開きます。

平面図の信号マーカーは「地上信号機リスト」の各行の「表示」で切り替えます。他列車の経路は「他列車リスト」で個別に切り替えます。

#### 言語とヘルプ

- **言語**：`中文` サブメニューの `简体` で簡体字中国語、`台湾繁體` で繁体字中国語（台湾）、`香港繁體` で繁体字中国語（香港）を選びます。`English` と `日本語` は `中文` サブメニューと同じ階層にあります。現在の言語にはチェックが付き、選択は保存されて次回起動時に復元されます。
- **ヘルプ**：オンラインドキュメント、不具合報告ページ、このアプリについての画面を開きます。

### 3. ツールバー

- **開く**：マップまたはシナリオファイルを選択して開きます。
- **再読込**：マップ、起動中の 3D シーン、現在の単体モデルを読み直します。`F5` と同じ操作です。
- **線形を再読込**：マップを読み直して軌道形状と配置を更新し、読み込み済みのシーンモデルとカメラ位置を可能な範囲で維持します。外部エディターで路線コードを変更した後の更新に使います。
- **編集モード**：編集の有効・無効を切り替えます。初回は注意事項を表示します。
- **マップ要素を追加**：編集が有効で、編集データの読み込みが完了すると、マップ要素追加ウィザードを開けます。
- **保存**：適用済みのマップ変更とシナリオ変更をソースファイルに保存します。ショートカットは `Ctrl+Shift+S`。リソースリストとカスタムメッセージの下書きは、先に各テーブルで適用してください。
- **元に戻す**：確認後、未保存の変更、リソースリスト・カスタムメッセージの下書き、シナリオの変更をすべて破棄し、メモリ内の作業コピーを前回保存時に戻します。
- **駅ジャンプ**：駅を選ぶと 2D ビューが移動します。3D シーンが起動中なら、カメラも移動します。
- **距離へジャンプ(m)**：数値を入力して「ジャンプ」を押すか、入力欄で `Enter` を押します。3D シーンが起動中なら、カメラも移動します。

共通ショートカットは、再読込が `F5`、保存が `Ctrl+Shift+S` です。2D/3D キャンバスの操作は第 5 節・第 9 節を参照してください。

### 4. ステータスバーとコンソール

#### 下部ステータスバー

- 左側の `Err` と `Warn` はエラー・警告の件数です。この領域をクリックすると一覧を表示します。
- 右側には読み込み中、準備完了、適用中、保存完了などの状態を表示します。時間のかかる処理では、完了後に所要時間も表示します。

#### コンソール

読み込み、解析、モデル、編集のログ全体を表示します。マップが開かない、モデルが欠けている、保存に失敗する場合は、まずコンソールを確認してください。

適用・保存・削除の合計時間はステータスバー、段階別の時間はコンソールの `edit timing:` に表示します。

- **クリア**：ログ全体を消去し、エラー・警告の件数をリセットします。
- **コピー**：不具合報告用にログ全体をクリップボードへコピーします。
- 最下部を表示している間は新しいログを追尾します。上へスクロールすると過去のログを表示したままにできます。

### 5. 2D キャンバス

2D ビュー上部で「移動」「測定」を選びます。グリッドは「固定」で画面に固定、「可動」でマップと共に移動・拡大縮小・回転し、「なし」で非表示になります。平面図と下部グラフの境界は上下に、2 つのグラフ間の境界は左右にドラッグしてサイズを調整できます。

#### 平面図：移動モード

| 操作 | 機能 |
| --- | --- |
| 左ボタンでドラッグ | 平面図を移動 |
| マウスホイール | 拡大・縮小 |
| `Shift` + ホイール | 1 段階につき 5° 回転 |
| `Ctrl` + 左ドラッグ | キャンバスの中心を軸に連続回転 |
| 左ダブルクリック | マップ全体を画面に収める |
| マーカーを右クリック | 位置移動・検索・プレビューのメニューを開く。編集有効時は「プロパティ/編集」「削除」も表示 |

タッチ操作では、1 本指のドラッグで移動、2 本指で移動・拡大縮小・回転を同時に行えます。マーカーの長押しは右クリックと同じです。

#### 縦断面図と曲線半径図

縦断面図は距離程と標高、曲線半径図は左右の曲線と半径を表示します。左ドラッグで移動し、ホイールで横軸の距離程範囲を拡大・縮小します。移動モードのダブルクリックで全体表示に戻ります。タッチ操作では、横方向の 2 本指ピンチで距離程範囲を、縦断面図では縦方向のピンチで標高軸も拡大・縮小できます。

#### 平面図とグラフ：測定モード

- 軌道付近にポインターを合わせると、距離程、標高、勾配、曲線半径、その位置の速度制限を表示します。
- 平面図、縦断面図、曲線半径図をダブルクリックすると、3 つの計測位置をその距離程にそろえます。

#### マーカー、位置移動、編集

- 「補助情報」で表示するマーカーを選びます。
- 「曲線半径」を有効にすると、`Curve.Interpolate` の端点を緑色で表示し、評価済みの符号付き半径を添えます。半径を省略した点では引き継いだ値を表示します。
- マーカーの右クリックから対応するテーブル行へ移動できます。3D オブジェクトを持つ項目はシーン内にも移動できます。
- 編集を有効にすると、対応マーカーの右クリックから「プロパティ/編集」「削除」を選べます。自軌道の曲線・勾配と他軌道の編集制御点は、この状態で表示されます。`Curve.Interpolate` と `CG`・`CC`・`CF` は各表示設定に従います。
- 対応付けられた曲線・勾配の変化点は、縦断面図と曲線半径図からも編集メニューを開けます。

#### 背景画像

「2Dプロット」の背景画像グループで「インポート」から画像を選びます。「表示」で表示を切り替え、「調整」で位置、幅、高さ、回転、明るさを設定します。

駅が 2 つ以上あるマップでは、「駅に合わせる」を使えます。

1. 「駅1」を選び、「平面図で駅を選択」を押して、背景画像上の駅の位置をダブルクリックします。
2. 別の駅を「駅2」に選び、同様に位置を指定します。
3. 「適用」または「OK」で画像の位置、縮尺、回転を計算します。

画像パスと位置合わせの設定は、現在のマップまたはシナリオの履歴に保存され、次に開いた際に復元されます。

### 6. マップ情報テーブル

#### 共通操作

- 「マップ情報リスト」から必要なテーブルを開きます。位置移動メニューのある距離程セルを右クリックすると、平面図や起動中の 3D シーンの該当位置へ移動できます。
- ソースやリソースのパスを右クリックすると、ディレクトリを開けます。ポインターを合わせると、取得できた元の引数と解決済みの絶対パスを表示します。
- ストラクチャー、信号現示、サウンド、3D サウンドの各リストでは、「検索」を展開し、部分一致か完全一致を選び、検索語を入力して `Enter` または「検索」を押します。上下の矢印で結果を移動できます。英字の大文字・小文字は区別しません。
- 未使用項目の検索では、現在のマップから参照されていない定義を強調表示します。ストラクチャーは配置、Repeater、背景、信号、他列車からの参照を調べます。通常のサウンドは停車場の到着・出発音と、現在のリストの下書きも考慮します。
- マップ上の配置行でリソースキーを右クリックすると、対応するストラクチャー、信号現示、サウンドの定義へ移動できます。
- 編集有効時は、編集可能な要素のセルを右クリックして「プロパティ/編集」「削除」を選べます。一部のテーブルではダブルクリックでもプロパティを開けます。

#### 停車場とストラクチャー

- **停車場リスト**：上部に `Station.Put` の停止距離程、ドアの側、停止位置前後の許容範囲を表示し、右クリックの「プロパティ/編集」で変更します。下部では `Station.Load` から読み込んだ駅名、到着・出発時刻、停車時間、サウンドなどをセル内で編集します。
- **マップストラクチャーリスト**：`Structure.Put` と `Structure.Put0` を表示し、平面図、3D シーン、モデル定義へ移動できます。
- **ストラクチャーリスト（PutBetween）**：2 軌道の間に合わせて変形する `Structure.PutBetween` を表示します。
- **ストラクチャーリスト**：structureKey とモデルパスを表示します。キーの右クリックからモデルをプレビューしたり、開いている同種のマップ要素追加ウィザードにキーを入力したりできます。
- **連続ストラクチャーリスト**：同じキーの `Repeater.Begin`・`Begin0`・`End` を区間にまとめ、始点・終点・変化点へ移動できます。「プロパティ/編集」で区間ごとのパラメーター、モデル順、終了距離程を変更します。詳細は第 10 節を参照してください。
- **他列車リスト**：他列車の定義、停止位置、読み取り専用の `Train.Enable` 時刻を表示します。各経路の表示を個別に切り替え、平面図の停止位置へ移動できます。

#### 軌道形状、信号、閉そく

- **他軌道**：「表示」「すべて選択」で 2D/3D の軌道表示を切り替えます。開始・終了距離程と色は 2D 表示の設定です。編集有効時は「キー」を右クリックして対応する `Track[...]` 文を一括で改名できます。Structure、Signal、Repeater 内の軌道参照は別途変更してください。
- **軌道変位・粘着特性変化点・速度制限点の各リスト**：対応位置を表示し、2D/3D の該当箇所へ移動できます。速度制限の Begin と End は個別に存在でき、End では距離程を編集します。
- **信号現示リスト**：現示定義とストラクチャーキーを表示し、キーからモデルへ移動できます。
- **地上信号機リスト**：`Signal.Put` の位置とパラメーターを表示します。各行の「表示」で平面図のマーカーを切り替えます。
- **閉そく一覧**：`Section.Begin`・`BeginNew` の信号インデックスと、`Section.SetSpeedLimit`・`Signal.SpeedLimit` の現示別制限速度を表示します。「プロパティ/編集」の `+`、`-`、上下矢印でパラメーターを追加・削除・並べ替えします。現示別制限速度の `null` は制限なしを表します。各行には最大 508 パラメーターを表示し、全件は「プロパティ/編集」で確認できます。
- **地上子リスト**：`Beacon.Put` を表示し、その位置へ移動できます。
- **変数リスト**：名前の大文字・小文字を区別せず、すべての代入を変数ごとにまとめます。ポインターを合わせると元の式を表示します。テーブルは読み取り専用です。

#### サウンドと効果

- **サウンドファイルリスト・3Dサウンドファイルリスト**：キー、パス、バッファ数を表示します。ファイルのディレクトリを開くか、対応するマップ要素追加ウィザードにキーを入力できます。
- **サウンド再生点・固定音源・走行音変化点・フランジきしり音変化点・分岐器通過音再生点の各リスト**：再生位置や変化位置を表示し、その位置へ移動できます。
- **背景変化点・運転台明るさ変化点・霧効果変化点・レガシー霧効果変化点・風景描画距離変化点の各リスト**：対応する効果を表示し、その位置へ移動できます。
- **光源**：`Light.Ambient` と `Light.Diffuse` の RGB、`Light.Direction` の pitch/yaw を表示します。編集有効時にパラメーターを変更し、このウィンドウの「適用」、ツールバーの「保存」の順に操作します。「新規」で未定義の項目を追加し、「削除」で既存項目を削除できます。
- **シナリオファイル**：開いているシナリオの各項目と候補を表示します。編集・保存は第 2 節を参照してください。

#### リソースリストのセル内編集

編集を有効にすると、停車場定義、ストラクチャー、信号現示、サウンド、3D サウンドの各リストで次の操作ができます。

- 編集可能なセルをダブルクリックして入力し、`Enter` またはセルからフォーカスを外して下書きに反映します。右クリックでは前後への行挿入、行全体の上下移動、セルのクリア、行全体の削除ができます。リソースパスのセルには「ファイルを選択」もあります。
- 空のリストには「行を追加」で最初の行を作成します。
- 「ファイルを選択」は、可能なら相対パス、それ以外は絶対パスを設定します。
- 信号現示の通常行とグレア（glare）行は、ひとまとまりで移動・削除します。新しい通常行は 6 フィールドで作成し、「グレアを追加」で対応行を追加できます。
- テーブルの「適用」でメモリ内のプレビューを更新します。すべての下書きを適用してから、ツールバーの「保存」でファイルに書き込みます。

信号現示リストは、末尾の空フィールドを含めた各 CSV 行の実際のフィールド数を扱います。その行に存在しないセルは斜線で示し、存在する空セルは編集できます。ストラクチャーキーの表示は最大 509 列で、それを超えるフィールドはソースと下書きに保持し、案内を表示します。

- CSV セルの右クリックから「右端にセルを追加」「末尾の空セルを削除」「右端のセルを削除」を選べます。通常行とグレア行は異なるフィールド数を持てます。
- 「すべての列数を揃える」は最も長い行に合わせて各行を埋めます。「右側に列を追加」「右端の列を削除」は各行に 1 セルずつ作用し、「すべての末尾空セルを削除」は各行の末尾を個別に処理します。
- 各行には先頭の CSV フィールドと、最低 1 つのストラクチャーキーフィールドを残します。キーは空でも構いません。グレア行の先頭は空欄に固定され、行を消す場合は「グレアを削除」を使います。
- 内容のある最終セルの削除には確認が必要です。列の一括操作は表示上限を超えるフィールドにも適用されます。

既存の連続したグレア行は、結合した 1 行として表示します。編集時は合計フィールド数を維持してください。移動と「グレアを削除」はグループ全体に作用します。セル・列の操作後は「適用」「保存」の順に操作します。

マップは各種類のリソースリストを 1 つずつ読み込めます。未設定のリストはテーブルの「新規作成またはファイルをインポート」で追加します。置換する場合は上部の「ソースパス」を右クリックし、「ファイルを変更...」を選びます。そのリストに未適用・未保存の変更がある場合は、破棄する前に確認します。

対応バージョンは Station List 0.04 以降、Structure List 1.00 以降、Signal Aspects List と Sound List は 2.00 以降です。通常のサウンドと 3D サウンドは共通の Sound List 形式を使います。リソースリストの標準コメント記号は `#` で、komapedit は CSV の二重引用符の外側にある `//` コメントも受け付けます。

### 7. ファイル構成図とテキストプレビュー

`補助情報 -> その他 -> ファイル構成図` から開きます。入口のマップを左側に、Include 先を階層ごとに右側へ表示します。ノードにポインターを合わせると、Include の引数と絶対パスを表示します。

#### ファイルを見る

- 有効なノードを右クリックし、「テキストをプレビュー」を選ぶと、読み取り専用の画面にソースと行番号を表示します。
- 「プロパティ/編集」のソースファイル名からもテキストプレビューを開けます。マップとリソースリストのプレビューは「適用」で更新されるため、保存前にソースの仕上がりを確認できます。
- 「エクスプローラーで開く」は対象ディレクトリを開きます。ディレクトリがない場合はコンソールに記録します。
- 存在しない、または無効な Include 先は赤色で表示します。そのノードではテキストプレビュー、サブマップのインポート、新規作成が無効になります。

#### Include の編集

次の操作は編集を有効にして行います。

- **参照ファイルを変更...**：新しい `.txt`・`.csv` のサブマップを選び、親ファイルの Include パスを書き換えます。可能なら相対パス、必要に応じて絶対パスを使います。
- **Include の参照を解除**：親ファイルから Include 文を削除します。後続の文がそのサブマップのデータに依存している場合は解除できません。
- **サブマップのインポート**：既存の BVE マップを選び、現在のノードが表すファイルに Include を追加します。
- **サブマップの新規作成**：新しいパスに、`BveTs Map 2.02:utf-8` ヘッダー、BOM なし UTF-8、CRLF 改行の空マップを作成し、Include を追加します。

新しい Include は、そのファイル内の最初の距離程文より前にある最後の Include の後ろへ挿入します。該当する Include がなければ最初の距離程文の前、両方なければファイル末尾に追加します。変更はプレビューに即時反映し、「保存」で親マップに書き込みます。

komapedit では各 Map ファイルの `distance` は `0` から始まり、Include から戻ると親の距離程を復元します。通常の `$variables` は共有します。サブマップを親に対する相対位置で配置するには、Include の前に `$dis=distance;` を代入し、サブマップで `$dis+offset;` を使って距離程を設定します。

### 8. 3D モデルプレビュー

`3Dビュー -> ストラクチャーモデルプレビュー` を開き、次のいずれかの方法でモデルを開きます。

- ツールバーの「ファイルを開く」から任意のモデルファイルを選べます。ストラクチャーリストに登録されていない `.x` ファイルも開けます。ダイアログの初期ディレクトリは、現在プレビュー中のモデルのディレクトリ、まだモデルを開いていない場合はマップのディレクトリです。
- ストラクチャーリストの structureKey を右クリックして「モデルをプレビュー」を選びます。

ツールバーの操作:

- **ストラクチャーリスト**：モデルの一覧を開きます。
- **ファイルを開く**：ストラクチャーリストの項目がなくても任意のモデルファイルを選択。
- **再読込**：現在のモデル、マテリアル、テクスチャを読み直します。
- **クリア**：現在のモデルをプレビューから除きます。
- **背景色**：任意の RGB 色、または白・黒・灰・青・緑のプリセットを選びます。
- 左ドラッグでモデルを回転し、ホイールで拡大・縮小します。

モデルやテクスチャの読み込みに失敗した場合は、コンソールで詳細を確認してください。

### 9. 3D シーンプレビュー

`3Dビュー -> 3Dシーンプレビュー` を開き、「3Dシーンプレビューを開始」を押します。マップを開く・再読込するたびに開始するには、`オプション -> 3Dキャンバス設定` の「地図を開くときにシーンプレビューを自動読み込み」を有効にします。既定では無効です。

ウィンドウ上部には、開始、「再読込（モデル）」、「閉じる」の操作があります。

- 「再読込（モデル）」は現在のマップとカメラ位置を維持し、シーンモデルを読み直します。
- 「閉じる」はシーンを解放します。プレビューウィンドウは開いたままにできます。

#### 移動モードとショートカット

ポインターが 3D キャンバス上にあるとき、次の操作が使えます。

キーボード移動は「移動」「選択」「キロ程選択」の各モードで使えます。左ドラッグによる視点回転は移動モードで行います。

| 操作 | 機能 |
| --- | --- |
| 左ボタンでドラッグ | 移動モードで視点を回転 |
| `W` / `S` | 路線に沿って前進・後退 |
| `A` / `D` | 左右へ移動 |
| `R` / `F` | 上下へ移動 |
| `Ctrl` を押しながら上記キー | 高速移動 |
| `X` | 現在の距離程の自軌道中心上に、既定のカメラ姿勢で戻る |

速度は「3Dキャンバス設定」で変更します。ツールバーから駅や距離程へジャンプできます。自軌道の始点より後方 100 m まで移動可能です。平面図への現在位置表示を有効にすると、2D 平面図にカメラ位置を表示します。

#### 選択モード

- オブジェクトやマーカーにポインターを合わせると強調表示します。
- 右クリックからマップ情報テーブルへ移動できます。Repeater では始点と終点・変化点への移動も選べます。
- 信号機を右クリックし、「信号現示を切替」から現示インデックスとストラクチャーキーに対応するプレビューモデルを選べます。
- 編集有効時は同じメニューに「プロパティ/編集」と削除操作が加わります。編集ギズモは第 10 節を参照してください。

#### キロ程選択モード

- ポインター付近に、自軌道の平面上で最も近い 1 m 単位の横断線と距離程を表示します。
- 編集有効時にその位置を右クリックし、「現在のキロ程にマップ要素を追加」を選ぶと、ウィザードの `distance` に自動入力します。

#### シーン内の情報表示と設定

カメラ位置、現在の曲線半径とカント、勾配、速度制限、閉そくの信号速度、次駅情報を表示します。`Curve.Interpolate` の区間では両端の半径・カント・曲線方向を表示し、両端の半径が `0` なら「直線」と表示します。下部にはシーンのチャンク数、インスタンス数、読み込み済みモデル数、フレームレートを表示します。

FPS はシーンキャンバスの更新頻度です。更新が止まっている間は直前の値を保持します。

`オプション -> 3Dキャンバス設定` で次を調整できます。

- **描画距離**：カメラ前方の表示範囲。「マップ文に応じて描画距離を調整」を有効にすると、`DrawDistance.Change` の値でも範囲を制限します。
- **霧効果**：マップの霧のプレビューを切り替えます。
- **編集用コンポーネントサイズ・カメラ移動速度**：ギズモサイズとキーボード移動速度を変更します。
- **パフォーマンス警告**：描画中のインスタンス数が警告しきい値を超えると黄色、重大警告のしきい値を超えると赤色になります。

関連マーカーの表示状態は「補助情報」と連動します。

霧は、指数関数を使う `Fog.Interpolate`・`Fog.Set` と、線形の互換構文 `Legacy.Fog` に対応します。同種のノード間は補間し、種類が異なる場合は後のノードで切り替えます。`Legacy.Fog` の start/end はカメラの奥行き方向の距離（m）、RGB は 0–255 です。距離程 0 の指定は即時反映し、それ以降は前後が両方とも線形の霧なら 25 m かけて移行します。どちらもテーブルやマーカーから編集でき、ウィザードの「効果」で作成できます。

#### シーン内の標識

「補助情報」で表示を切り替えます。「曲線半径」が有効な場合、`Curve.Interpolate` 点に半径、カント、曲線方向を表示し、半径 0 は `Intpl. 0` と表示します。標識は選択と強調表示に対応し、編集有効時は右クリックから編集・削除できます。

### 10. 編集・新規作成・保存

#### 編集を始める前に

ツールバーで初めて編集を有効にすると、確認画面を表示します。「今後表示しない」を選んで確定することもできます。

編集データの読み込み完了後に操作を始めてください。「プロパティ/編集」、光源、ウィザードで値を入力したら、画面を離れる前に「適用」を押します。編集の無効化、別の文書を開く操作、再読込、終了の際は、残っている変更の扱いを確認します。

#### 下書き・適用・保存・元に戻す

マップとリソースリストは、次の順に編集します。

1. **下書きを編集**：「プロパティ/編集」、リソーステーブル、ウィザードで値を入力します。一部のオブジェクトは入力中もプレビューできます。
2. **プレビューに適用**：画面内の「適用」で検証し、メモリ内の作業コピーを再解析して、2D ビュー、テーブル、3D プレビューを更新します。
3. **ファイルに保存**：ツールバーの「保存」または `Ctrl+Shift+S` で、適用済みの変更を対応するマップ、Include 先、リソースリストに書き込みます。

リソースリストとカスタムメッセージは、すべての下書きを適用してから保存します。シナリオの入力欄の変更は、ツールバーの「保存」で直接保存します。「元に戻す」はメモリ内を前回保存時に戻します。外部エディターによる変更を読む場合は「再読込」を使います。

保存前に変更結果を再解析・検証し、元の文字コード、BOM、改行コードを維持します。新しい文字を元の文字コードで表せない場合や、別のプログラムがファイルを変更している場合は、理由を表示して保存を中止します。

#### 既存のマップ要素を編集・削除する

1. テーブルの項目または 2D/3D マーカーを右クリックし、「プロパティ/編集」を開きます。
2. ソースファイル、ソース位置、元の文を確認して、各項目を変更します。
3. 「適用」でメモリ内のプレビューを更新します。
4. 2D ビュー、テーブル、3D の結果を確認し、ツールバーの「保存」で確定します。

停車場、ストラクチャー、信号、地上子、Repeater、閉そく、速度制限、曲線・勾配、他軌道、軌道変位、サウンド、背景、粘着特性、運転台の明るさ、霧、光源、描画距離、先行列車の通過点などを編集できます。右クリックの「削除」はプレビューに削除を反映し、その後の保存でソースファイルに書き込みます。

「座標オフセットを追加」「座標オフセットを削除」で、`Structure.Put`・`Put0`、`Repeater.Begin`・`Begin0` を相互変換できます。0 以外のオフセットを削除する場合は確認が必要です。短縮形の `Signal.Put` で Z、回転、tilt、span を編集する場合も、完全な形式への変換を確認します。

#### Repeater の区間編集

- 「プロパティ/編集」の「前へ」「次へ」で、同じキーの各区間を移動します。
- ストラクチャーキー一覧の `+`、`-`、上下矢印で、繰り返し配置するモデルを追加・削除・並べ替えします。
- 「変化点を挿入」は現在のパラメーターを入力済みのウィザードを開きます。新しい距離程と値を入力して適用します。最終区間に End がなければ「終了位置を追加」で作成できます。
- 複数区間の削除メニューには「すべて削除」「対応する変化点を削除」「変化点までトリム」「変化点から開始」があります。順に、全区間、1 つの変化点、それより後の区間、それより前の区間を削除します。プレビューを確認後に保存してください。

#### 3D シーンでの位置調整

「プロパティ/編集」を開き、対応するオブジェクトのギズモをドラッグして下書きを変更します。その後、上記の手順で適用・保存します。

- `Structure.Put`、完全な形式の `Signal.Put`、`Repeater.Begin` は X/Y/Z 軸で座標を変更します。
- `Sound3D[soundKey].Put(x, y)` は X/Y で相対位置を 0.001 m 単位、Z で距離程を 1 m 単位で変更します。
- `Structure.Put0` と `Repeater.Begin0` は Z で距離程を 1 m 単位で変更します。座標オフセットを追加すると、全座標用のギズモを使えます。
- 明示的な End を持つ Repeater は、終点の Z 軸で終了距離程を 1 m 単位で変更します。
- `Structure.PutBetween` は Z 軸で距離程を 1 m 単位で変更し、変形後のモデルを随時再計算します。

#### マップ要素追加ウィザード

ツールバーの「マップ要素を追加」、または 3D の「キロ程選択」モードで現在位置を右クリックして開きます。書き込み先のソースファイルとテンプレートを選び、パラメーターを入力します。空ファイルや距離程文のないファイルを含め、読み込み済みのすべてのマップソースを指定できます。

要素の作成・移動時は、他の文とコメントを保持して距離程文を自動配置します。手動で位置を決める場合は、テキストプレビューで強調表示された文の境界を選び、「OK」で進みます。距離式を求められた場合は、そのソース文字列を入力して「適用」を押します。

対応要素は次の分類から選びます。

- **ストラクチャー**：`Structure.Put`、`Put0`、`PutBetween`、`Repeater.Begin`・`Begin0`・`End`。
- **停車場**：`Station.Put`。
- **軌道形状**：曲線、勾配、軌間、カント中心、補間関数、軌道変位、粘着特性。
- **他軌道**：位置、X/Y 補間、カントに関する `Track.*` 文。
- **信号**：信号機、速度制限、閉そく、信号速度、地上子、`PreTrain.Pass`。
- **サウンド**：マップサウンド、3D 音源、走行音、フランジきしり音、分岐器通過音。
- **効果**：背景、運転台の明るさ、霧、光源、描画距離。
- **その他**：マップのヘッダー直下にコメントとして保存するカスタムメッセージ。

「適用」は要素を作成してプレビューを更新します。「適用して編集」はウィザードを閉じ、新しい要素の「プロパティ/編集」またはカスタムメッセージのタブを開きます。Repeater の変化点ウィザードでは「適用」を使います。

テンプレートの入力上の要点：

- **Repeater**：Begin、End、または両方を追加できます。対で作成する場合、終了距離程は開始距離程以上とし、同じキーの対の区間が重ならないようにします。区間内で値を変える場合は「変化点を挿入」を使います。
- **曲線と勾配**：始点、終点、または両方を追加できます。曲線は `Curve.Begin`・`Curve.Change` で開始し `Curve.End` で終了、勾配は `Gradient.Begin`・`End` を使います。Begin/End には対応する移行区間の開始点を付けられます。`Curve.Change` は半径を直接変更します。
- **曲線補間点**：`Curve.Interpolate` は距離程が必須で、半径・カントの既定値は `0`。カントのチェックを外すと引数 1 個、半径も外すと引数 0 個の形式になります。
- **他軌道**：省略可能な末尾の引数は順番に有効にします。たとえば `radiusV` より先に `radiusH` を有効にします。新しい trackKey を指定すると他軌道を追加します。数値キーと引用符付きの文字列キーは区別します。
- **先行列車の通過点**：`passTime` は `hh:mm:ss`、または午前 0 時からの秒数で入力します。入力欄にポインターを合わせると書式を確認できます。
- **光源**：距離程 `0` に作成します。RGB は `0` から `1`。各種類は Include を含むマップ全体で 1 つずつ定義できます。

#### カスタムメッセージ（Message from Creator）

ウィザードで「その他 -> カスタムメッセージ」を選び、マップソースを指定して 1 行のメッセージを入力します。適用・保存すると、ヘッダーの後の空行に続けて、次のコメント形式で書き込みます。既存のメッセージブロックがある場合は末尾へ追加します。

```plaintext
BveTs Map 2.02

//--kme--message-from-creator:"content"
```

通常の BVE `//` コメントとして保存します。内容は空白・引用符・バックスラッシュを含め、そのまま保持します。空のメッセージも使用でき、入力は NUL 文字を含まない 1 行とします。

マップやシナリオを開くと、ルートマップと読み込み済み Include のメッセージを表示します。複数ある場合はページで切り替え、同じファイルを複数回参照していても各メッセージを 1 回ずつ表示します。「次回から表示しない」を選んで確定すると、ルートマップごとに設定を記憶します。

`補助情報 -> その他 -> カスタムメッセージ` では、いつでもソースファイル、行番号、本文を確認できます。キーワードを入力し、`Enter` または「検索」でファイル名・本文を検索します。上下矢印で結果を移動できます。

編集有効時は本文セルをダブルクリックして編集し、`Enter` またはフォーカスを外して下書きに反映します。`Esc` は入力中の変更を取り消します。セルの右クリックから「行全体を削除」を選べます。タブの「適用」、ツールバーの「保存」の順に操作してください。

#### 新規ファイルウィザード

`ファイル -> 新規作成...` で、Map、Scenario、Structure List、Signal Aspects List、Sound List、Sound3D 用の Sound List、Station List を作成できます。

1. 種類を選び、拡張子を除くファイル名、`.txt`・`.csv` の別、保存先ディレクトリを指定します。
2. リソースリストでは「ファイルをインポート」で既存の `.txt`・`.csv` から名前・ディレクトリ・拡張子を入力し、必要に応じて変更できます。
3. シナリオでは必要な項目を入力します。空欄の項目は省略します。「ファイルを選択」で Route、Vehicle、Image に相対パスを入力できます。
4. マップを読み込み済みの場合、Map やリソースリストの作成には編集を有効にし、「次のファイルに参照を追加」で対象ソースを確認します。マップ未読み込み時は単独のファイルを作成できます。
5. 「確認」で作成、または既存ファイルを再利用します。サブマップを作成した場合は、親マップの参照を保存してから開きます。単独のマップとシナリオには「確認して読み込む」もあります。

既存の通常ファイルはそのまま再利用します。新しいファイルは UTF-8・CRLF で作成し、マップとリソースリストには標準ヘッダー、シナリオには標準の項目順で内容を書き込みます。

シナリオのテンプレートには `Title`、`Route`、`RouteTitle`、`Vehicle`、`VehicleTitle`、`Author`、`Image`、`Comment` の 8 項目があります。各パス項目は 1 パスを受け付け、値には `#`・`;` などのコメント文字を含めないでください。複数のパス候補と重みは、読み込み後にシナリオファイルのタブで編集できます。

ファイル自体はウィザードで直ちに作成します。`include` または対応する `*.Load` 参照はマップのプレビューに適用し、ツールバーの「保存」で書き込みます。各種類のリソースリストは 1 つずつ参照できます。参照先の置換には、テーブル上部の「ソースパス」の右クリックメニューを使います。

## 付録：CSV データ形式

### 自軌道の形状 CSV（出力）

`ファイル -> CSV 出力...` で現在の形状サンプルを出力します。ファイル名の形式：

```text
<output-folder-name>_owntrack.csv
```

ヘッダー：

```csv
#distance,x,y,z,direction,radius,gradient,interpolate_func,cant,center,gauge
```

各フィールドの意味：

| フィールド | 説明 |
| --- | --- |
| distance | マップの絶対距離程（m） |
| x | 勾配を水平面へ投影した後の自軌道の平面 X 座標（m） |
| y | 勾配を水平面へ投影した後の自軌道の平面 Y 座標（m） |
| z | 標高（m） |
| direction | 軌道の方向角（rad） |
| radius | 符号付き曲線半径（m）。正は右曲線、負は左曲線、0 は直線 |
| gradient | 勾配（‰） |
| interpolate_func | 補間方式。`0` はサイン半波長逓減、`1` は直線逓減 |
| cant | カント（m） |
| center | カントの回転中心の横方向座標（m） |
| gauge | 軌間（m） |

### 他軌道の形状 CSV（出力）

他軌道は 1 軌道につき 1 ファイルに出力します。ファイル名の形式：

```text
<output-folder-name>_<trackKey>.csv
```

trackKey 内の `\ / : * ? " < > |` は `_` に置換し、空のキーは `root` とします。各軌道の出力ファイル名は一意である必要があります。

ヘッダー：

```csv
#distance,x,y,z,interpolate_func,cant,center,gauge
```

各フィールドの意味：

| フィールド | 説明 |
| --- | --- |
| distance | マップの絶対距離程（m） |
| x | 水平面に投影した自軌道から算出する他軌道の平面 X 座標（m） |
| y | 水平面に投影した自軌道から算出する他軌道の平面 Y 座標（m） |
| z | 他軌道の標高（m） |
| interpolate_func | カントの補間方式。`0` はサイン半波長逓減、`1` は直線逓減 |
| cant | カント（m） |
| center | カントの回転中心の横方向座標（m） |
| gauge | 軌間（m） |

CSV には軌道形状を出力し、数値は小数点以下 6 桁で表します。
