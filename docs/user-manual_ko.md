# komapedit 사용자 매뉴얼

이 매뉴얼은 komapedit의 인터페이스, 미리 보기와 편집 방법, 내보낸 CSV의 형식을 설명합니다.

프로젝트 소개, 지원하는 BVE 맵 구문, 설치와 실행 방법은 [README](README_ko.md)를 참조하세요.

## 버그 신고

komapedit는 코드의 80% 이상이 바이브 코딩 결과물(vibeslop)로 이루어진 개인 프로젝트입니다.

비정상 종료, 표시 오류, komapedit와 BVE 사이의 맵 요소 동작 차이, 편집 또는 저장 실패를 발견하면 `도움말 → 버그 신고`를 선택하거나 [GitHub Issues](https://github.com/NewSapporoNingyo/komapedit/issues)를 방문하세요.

이슈는 원하는 언어로 작성할 수 있습니다. 개발자는 유효한 이슈의 영어 번역을 제공합니다. 풀 리퀘스트는 영어로 작성합니다.

같은 문제가 이미 등록되어 있는지 검색하고, 있으면 해당 이슈에 정보를 추가하세요. 새 문제라면 GitHub에 로그인하여 이슈를 만듭니다. 제목에는 기능과 증상을 짧게 적습니다. 예를 들어 “특정 맵을 연 뒤 3D 장면 미리 보기를 불러오면 비정상 종료”라고 쓸 수 있습니다.

**프로그램에서 실제로 발생한 오류나 예외를 이슈로 등록하세요.**

### 신고에 포함할 정보

- **운영 체제와 하드웨어** 정보를 적습니다. `Win+R`을 누르고 `winver`를 실행해 Windows 버전과 OS 빌드를 확인하고 시스템 아키텍처도 적습니다. 3D 표시나 성능 문제라면 CPU, RAM 용량, 그래픽 카드 모델, 드라이버 버전을 추가합니다.
- **프로그램 버전**과 입수 경로를 적습니다. 직접 빌드했다면 Debug/Release 유형과 컴파일러 버전을 포함합니다. 버전을 확인하기 어렵다면 다운로드 또는 빌드 날짜를 적습니다.
- **실제 동작과 기대 동작**을 설명하고 오류 메시지 전문을 포함합니다. 느려지거나 멈췄다면 어느 단계에서 얼마나 오래 지속되었는지 적습니다.
- **재현 절차**를 프로그램 실행과 파일 열기부터 순서대로 적습니다. 메뉴, 매개변수, 설정과 `적용` 또는 `저장`을 눌렀는지 포함합니다. 매번 발생하는지, 간헐적으로 발생하는지 적습니다. 특정 위치나 요소에 한정되면 거리, 요소 키 또는 원본 파일 위치를 적습니다.
- **콘솔 로그**는 관련 파일을 불러오는 시점부터 문제가 발생한 뒤까지의 전문을 포함합니다. 아래 절차를 따르고, 긴 로그는 `.txt` 파일로 첨부할 수 있습니다.
- **재현 파일**을 제공합니다. 특정 맵에서만 발생하면 가능할 때 그 맵을 제공하세요. 비공개 맵은 재현에 필요한 최소 파일만 골라 개발자에게 이메일로 보낼 수 있습니다. 맵, Include 하위 맵, 리소스 목록, 모델, 텍스처 사이의 상대 경로를 유지하세요. 공개 맵은 다운로드 링크를 제공하세요. 편집이나 저장 문제는 가능하면 변경 전후 파일과 달라진 부분을 함께 제공합니다.
- **스크린샷이나 녹화**로 인터페이스, 2D/3D 표시 또는 조작 순서의 문제를 보여 주세요. 검색과 분석을 위해 글로 쓴 설명과 로그도 포함합니다.

업로드 전에 로그, 스크린샷, 첨부 파일에 개인 경로 등의 정보가 있는지 확인하세요. GitHub Issues에 올릴 때는 공개할 수 있는 파일을 사용하고 가능한 한 재현 조건을 유지합니다.

### 콘솔 로그 가져오기

1. `보조 정보 → 기타 → 콘솔 창`에서 콘솔을 엽니다.
2. 재현할 수 있다면 테스트 파일이나 사본으로 절차를 반복합니다. 파일을 불러올 때부터 문제 발생 직후까지의 로그를 보존하세요.
3. 콘솔의 `복사`를 눌러 로그 전체를 클립보드에 복사합니다.
4. 이슈의 코드 블록에 붙여넣거나 UTF-8 텍스트 파일로 저장해 첨부합니다.

비정상 종료나 응답 없음, 시작 실패로 콘솔 로그를 복사하기 어려우면 마지막 조작과 오류 대화 상자 또는 스크린샷을 제공하세요. Windows 이벤트 뷰어에 관련 응용 프로그램 오류가 있으면 함께 첨부할 수 있습니다.

## 사용법

보기 창에서 맵을 살펴볼 수 있습니다. 파일을 수정하기 전에는 10절을 읽고 맵을 백업하세요.

### 1. 기본 창

- **상단 메뉴**에서 파일을 열고, 창을 표시하거나 숨기고, 2D/3D 설정을 바꾸고, 도움말을 엽니다.
- **도구 모음**에서 열기, 다시 불러오기, 편집, 저장, 역으로 이동, 거리로 이동을 실행합니다.
- **가운데 작업 공간**에는 2D 보기, 파일 구조도, 텍스트 미리 보기, 3D 모델 미리 보기와 3D 장면 미리 보기가 표시됩니다. 창을 탭으로 묶거나 끌어서 다른 위치에 도킹할 수 있습니다.
- **맵 정보 표**는 보통 오른쪽에 도킹하며 역, 구조물, 신호기, 소리 등의 맵 요소를 표시합니다.
- **콘솔 창**은 보통 오른쪽 아래에 도킹하며 맵과 모델 불러오기, 편집, 저장의 상세 로그를 표시합니다.
- **하단 상태 표시줄**은 현재 작업과 오류·경고 개수를 표시합니다.

닫은 창은 `맵 정보 목록`, `2D 보기`, `3D 보기` 또는 `보조 정보`에서 다시 열 수 있습니다. 창 표시 여부와 도킹 레이아웃은 자동으로 저장됩니다.

### 2. 상단 메뉴

#### 파일

- `새로 만들기...`에서 새 파일 마법사를 엽니다. 맵, 시나리오 또는 리소스 목록 파일을 만들 수 있습니다. 자세한 내용은 10절을 참조하세요.
- `열기...`에서 `.txt` 또는 `.csv` 맵·시나리오 파일을 선택합니다. 도구 모음의 `열기`도 같은 동작을 합니다.
- `최근 맵`에서 최근 맵을 열거나 기록을 비웁니다.
- `다시 불러오기`는 현재 맵을 다시 읽고, 실행 중인 3D 장면을 갱신하고, 미리 보는 모델을 다시 읽습니다. 단축키는 `F5`입니다. 저장하지 않은 변경이 있으면 먼저 확인합니다.
- `CSV 내보내기...`에서 폴더를 선택해 기준 궤도와 모든 다른 궤도의 현재 선형 데이터를 내보냅니다. 같은 이름의 기존 파일은 덮어씁니다. 여러 궤도가 같은 출력 파일 이름을 만들면 내보내기를 중지하고 콘솔에 이유를 표시합니다. CSV 필드는 부록을 참조하세요.
- `종료`는 프로그램을 닫습니다. 저장하지 않은 변경을 저장하거나 버리거나, 종료를 취소할 수 있습니다.

`BveTs Scenario 2.00` 파일을 열면 시나리오 정보를 확인하고 해당 맵을 불러올 수 있습니다.

- `맵 정보 목록 → 기타 → 시나리오 파일`에서 필드, Route/Vehicle 경로, 가중치를 확인합니다. 편집 모드에서 입력란을 바꿀 수 있습니다. 제목, 제작자, 설명 및 Image 경로가 빠져 있으면 입력해 추가할 수 있습니다.
- 경로를 마우스 오른쪽 버튼으로 클릭하여 파일을 선택하거나 폴더를 엽니다. Route와 Vehicle 후보를 추가·삭제·재정렬할 수 있습니다. Route에는 후보를 하나 이상 유지하며, Vehicle은 비울 수 있습니다. 새 후보의 가중치 기본값은 `1`입니다. 후보에는 경로가 필요하며 가중치는 `0`보다 커야 합니다.
- 유효한 Route 후보가 하나면 해당 맵을 바로 불러옵니다. 여러 개면 사용할 후보를 선택합니다.
- Route가 없거나 유효하지 않거나 선택을 취소해도 시나리오는 보고 편집할 수 있습니다. Vehicle 항목에는 참조 경로와 가중치가 표시됩니다.
- 도구 모음의 `저장` 또는 `Ctrl+Shift+S`로 시나리오 변경을 해당 파일에 바로 씁니다. 맵과 시나리오를 모두 변경했다면 맵을 먼저 저장합니다. Route 후보의 경로나 순서도 바뀌었다면 시나리오 저장을 다시 요청합니다. 저장한 뒤 `다시 불러오기`로 선택한 맵을 불러옵니다.
- 최근 파일, 배경 정렬 기록, 다시 불러오기는 시나리오 파일을 기준으로 합니다. 다시 불러오기는 시나리오를 읽고, 필요하면 Route를 선택한 뒤 모델을 갱신합니다. `궤도 선형 다시 불러오기`는 가능한 경우 장면 모델과 카메라를 유지합니다.

#### 옵션

- `UI 설정...`에서 글자 크기, UI 요소 크기, 테마 색상을 바꿉니다.
- `2D 캔버스 설정 → 캔버스 요소 크기`에서 마커 크기와 기준 궤도, 다른 궤도, 차트 마커, 격자의 선 너비를 바꿉니다.
- `2D 캔버스 설정 → 표시 범위...`에서 거리의 최솟값과 최댓값을 입력하고 `적용`을 눌러 2D 표시 범위를 바꿉니다. `초기화`로 기본 범위를 채우고 `적용`으로 반영합니다.
- `2D 캔버스 설정 → 제어점...`에서 궤도 선형의 표본 범위와 간격을 바꿉니다. `적용`을 누르면 선형 데이터를 다시 생성합니다. 간격이 작을수록 곡선의 표본이 촘촘해집니다. CSV는 새 데이터를 내보냅니다.
- `3D 캔버스 설정`에서 장면 표시 거리, 편집 도구 크기, 카메라 속도, 안개, 맵 구문에 따른 표시 거리, 자동 불러오기, 성능 경고를 바꿉니다.

글자와 요소의 크기, 색상 및 3D 표시 매개변수는 변경하면서 미리 볼 수 있습니다. `확인`으로 저장하거나 `취소`로 창을 열기 전 값으로 되돌립니다.

#### 맵 정보 목록

역, 구조물, 궤도 선형, 신호, 소리, 효과, 기타 데이터로 묶인 표를 엽니다. 자세한 내용은 6절을 참조하세요.

#### 2D 보기

- 2D 보기 창 전체, 종단면도, 곡선 반경도를 표시하거나 숨깁니다.
- 종단면도의 구배 변경점, 구배 값, 다른 궤도를 표시하거나 숨깁니다.
- 배경 이미지를 가져오거나 표시·조정하고, 역 두 곳의 위치로 정렬합니다. 위치, 크기, 회전, 밝기를 조정할 수 있습니다.

#### 3D 보기

- `구조물 모델 미리 보기`로 단일 모델을 보는 창을 표시하거나 숨깁니다.
- `3D 장면 미리 보기`로 전체 맵의 장면을 보는 창을 표시하거나 숨깁니다.

#### 보조 정보

- 역, 궤도 선형, 신호, 소리, 효과 마커의 2D/3D 표시 여부를 선택합니다.
- `궤간 설정점`, `캔트 회전 중심 설정점`, `완화곡선 함수 설정점`은 각각 `CG`, `CC`, `CF` 마커를 표시합니다. `폐색 구간 마커`는 녹색 `S` 마커와 신호 인덱스를 표시합니다. 네 옵션은 기본적으로 꺼져 있습니다.
- `선행 열차 통과 지점`은 `PreTrain.Pass` 마커를 표시합니다. 편집 모드에서 마커를 오른쪽 클릭하면 거리나 통과 시각을 바꾸거나 삭제할 수 있습니다.
- `기준 궤도 마커`와 `평면도에 현재 위치 표시`는 3D 장면과 2D 평면도에 보조 정보를 표시합니다.
- `기타`의 `사용자 지정 메시지`, `파일 구조도`, `텍스트 미리 보기`, `콘솔 창`에서 해당 창을 엽니다.

평면도에 표시할 신호기 마커는 `지상 신호기 목록`에서 각 행의 `표시`로 설정합니다. 타 열차 경로는 `타 열차 목록`에서 열차별로 표시합니다.

#### 언어와 도움말

- `언어` 메뉴에서 `한국어`를 선택하면 바로 적용됩니다. 기본 언어인 중국어 간체에서는 `语言 → 한국어`를 선택합니다. `English`, `日本語`, `한국어`는 `中文` 하위 메뉴와 같은 단계에 있습니다. `中文`의 `简体`는 중국어 간체, `台湾繁體`는 대만 번체, `香港繁體`는 홍콩 번체입니다. 선택한 언어에 체크 표시가 생기고 다음 실행에도 복원됩니다.
- `도움말`에서 온라인 문서, 버그 신고 페이지 또는 프로그램 정보 창을 엽니다.

### 3. 도구 모음

- `열기`로 맵 또는 시나리오 파일을 선택해 엽니다.
- `다시 불러오기`는 맵을 다시 읽고, 실행 중인 3D 장면을 갱신하고, 미리 보는 모델을 다시 읽습니다. `F5`와 같습니다.
- `궤도 선형 다시 불러오기`는 맵을 다시 읽어 선형과 배치를 갱신합니다. 가능한 경우 불러온 3D 모델과 카메라 위치를 유지합니다. 외부에서 노선 원본을 편집한 뒤 미리 보기를 갱신할 때 사용합니다.
- `편집 모드`를 켜거나 끕니다. 처음 켤 때 편집 위험을 안내합니다.
- `맵 요소 추가`는 편집 모드를 켜고 편집 데이터를 불러온 뒤 맵 요소 만들기 마법사를 엽니다.
- `저장`은 적용한 맵 변경과 시나리오 변경을 원본 파일에 씁니다. 단축키는 `Ctrl+Shift+S`입니다. 리소스 목록과 사용자 지정 메시지의 초안은 해당 표에서 먼저 적용합니다.
- `되돌리기`는 확인 후 대기 중인 변경, 리소스 목록과 사용자 지정 메시지 초안, 시나리오 변경을 폐기합니다. 메모리 작업 사본을 마지막 저장 상태로 되돌립니다.
- `역으로 이동`에서 역을 선택하면 2D 보기가 그 역으로 이동합니다. 3D 장면이 실행 중이면 카메라도 이동합니다.
- `거리로 이동 (m)`에 숫자를 입력한 뒤 `이동`을 클릭하거나 입력란에서 `Enter`를 누릅니다. 3D 장면이 실행 중이면 카메라도 이동합니다.

전역 단축키는 다시 불러오기 `F5`와 저장 `Ctrl+Shift+S`입니다. 2D와 3D 캔버스 조작은 5절과 9절을 참조하세요.

### 4. 상태 표시줄과 콘솔

#### 하단 상태 표시줄

- 왼쪽의 `Err`와 `Warn`에 오류 및 경고 개수가 표시됩니다. 이 영역을 클릭하면 요약을 확인할 수 있습니다.
- 오른쪽에는 불러오는 중, 준비 완료, 변경 사항을 적용하는 중, 저장 완료 등의 상태가 표시됩니다. 시간이 오래 걸린 작업을 마치면 소요 시간도 표시합니다.

#### 콘솔 창

콘솔에는 불러오기, 파싱, 모델과 편집 로그가 모두 표시됩니다. 맵이 열리지 않거나 모델이 빠졌거나 저장에 실패하면 콘솔을 확인하세요.

적용, 저장, 삭제의 총 소요 시간은 상태 표시줄에 표시됩니다. 단계별 시간은 콘솔의 `edit timing:` 로그에 기록됩니다.

- `비우기`는 로그 전체를 지우고 오류와 경고 개수를 초기화합니다.
- `복사`는 버그 신고에 첨부할 수 있도록 로그 전체를 클립보드에 복사합니다.
- 화면이 로그 맨 아래에 있으면 새 메시지를 따라갑니다. 위로 스크롤하면 이전 메시지를 계속 볼 수 있습니다.

### 5. 2D 캔버스

2D 보기 위쪽에서 `이동` 또는 `측정` 모드를 선택합니다. `고정` 격자는 화면에 고정되고, `이동` 격자는 맵을 따라 이동·확대·회전합니다. `없음`을 선택하면 격자를 숨깁니다. 평면도와 아래 차트 사이의 분할선을 위아래로 끌어 높이를 조절합니다. 두 차트 사이의 분할선을 좌우로 끌어 너비를 조절합니다.

#### 평면도 이동 모드

| 조작 | 기능 |
| --- | --- |
| 마우스 왼쪽 버튼으로 끌기 | 평면도 이동 |
| 마우스 휠 돌리기 | 평면도 확대·축소 |
| `Shift` + 마우스 휠 | 한 단계에 5° 회전 |
| `Ctrl` + 왼쪽 버튼으로 끌기 | 캔버스 중심을 기준으로 연속 회전 |
| 마우스 왼쪽 버튼 두 번 클릭 | 맵 전체를 창에 맞추기 |
| 마커를 오른쪽 클릭 | 위치 찾기, 검색 또는 미리 보기 메뉴 열기. 편집 모드에서는 `속성/편집`과 `삭제`도 표시 |

터치 화면에서는 한 손가락으로 끌어 이동합니다. 두 손가락으로 이동, 확대·축소, 회전을 동시에 할 수 있습니다. 마커를 길게 누르면 오른쪽 클릭과 같은 메뉴를 엽니다.

#### 종단면도와 곡선 반경도

종단면도는 거리와 표고를 표시합니다. 곡선 반경도는 좌곡선과 우곡선을 구분하고 반경을 표시합니다. 마우스 왼쪽 버튼으로 끌어 이동하고 휠을 돌려 거리축을 확대·축소합니다. `이동` 모드에서 두 번 클릭하면 전체 범위를 표시합니다. 터치 화면에서는 두 손가락을 가로로 오므리거나 벌려 거리 범위를 바꿉니다. 종단면도에서는 세로 동작으로 표고축도 확대·축소할 수 있습니다.

#### 평면도와 차트의 측정 모드

- 포인터를 궤도 근처에 두면 거리, 표고, 구배, 곡선 반경 및 현재 제한 속도를 표시합니다.
- 평면도, 종단면도, 곡선 반경도 중 하나를 두 번 클릭하면 세 보기의 측정 위치가 해당 거리로 함께 이동합니다.

#### 마커, 위치 찾기, 편집

- `보조 정보`에서 표시할 마커를 고릅니다.
- `곡선 반경`을 켜면 `Curve.Interpolate` 끝점이 녹색 마커로 표시되며 계산한 부호 있는 반경이 함께 표시됩니다. 반경을 생략한 구문은 이전 값을 표시합니다.
- 마커를 오른쪽 클릭하면 대응하는 표 행을 찾을 수 있습니다. 3D 객체가 있는 항목은 장면에서도 찾을 수 있습니다.
- 편집 모드에서 지원되는 마커를 오른쪽 클릭하면 `속성/편집` 또는 `삭제`를 선택할 수 있습니다. 기준 궤도의 곡선·구배와 다른 궤도의 편집 제어점은 이 모드에서 표시됩니다. `Curve.Interpolate` 및 `CG`/`CC`/`CF` 마커는 각각의 표시 설정을 따릅니다.
- 짝을 이루는 곡선이나 구배 변경점은 종단면도와 곡선 반경도에서도 편집 메뉴를 제공합니다.

#### 배경 이미지

`2D 보기`의 `배경 이미지` 그룹에서 `가져오기`를 눌러 이미지를 선택합니다. `표시`로 표시 여부를 바꾸고 `조정`에서 위치, 너비, 높이, 회전, 밝기를 설정합니다.

역이 두 곳 이상인 맵은 `역에 맞춰 정렬`을 사용할 수 있습니다.

1. 첫 번째 역을 선택하고 `평면도에서 역 선택`을 누른 다음 배경 이미지의 해당 역 위치를 두 번 클릭합니다.
2. 두 번째 역에 다른 역을 선택하고 같은 방법으로 위치를 지정합니다.
3. `적용` 또는 `확인`을 눌러 이미지의 위치, 크기, 회전을 계산합니다.

이미지 경로와 정렬 설정은 현재 맵 또는 시나리오에 저장되며, 다시 열 때 복원됩니다.

### 6. 맵 정보 표

#### 공통 작업

- `맵 정보 목록`에서 필요한 표를 엽니다. 위치 찾기 메뉴가 있는 거리 셀을 오른쪽 클릭하여 평면도나 실행 중인 3D 장면의 해당 위치로 이동합니다.
- 원본 파일이나 리소스 파일 경로를 오른쪽 클릭하면 폴더를 열 수 있습니다. 경로에 마우스를 올리면 해당하는 원래 인수와 해석한 절대 경로를 확인할 수 있습니다.
- 구조물 목록, 신호 현시 목록, 소리 파일 목록, 3D 소리 파일 목록에서 `찾기`를 펼칩니다. `부분 일치` 또는 `완전 일치`를 선택하고 검색어를 입력한 뒤 `Enter`를 누르거나 `찾기`를 클릭합니다. 위아래 화살표로 결과 사이를 이동합니다. 영어의 대소문자는 구분하지 않습니다.
- 미사용 항목 찾기는 현재 맵에서 참조하지 않는 정의를 강조합니다. 구조물 검색은 배치, 반복 구조물, 배경, 신호기, 타 열차의 참조를 확인합니다. 일반 소리 검색은 역의 도착음과 출발음, 현재 목록 초안도 반영합니다.
- 맵 배치 행의 리소스 키를 오른쪽 클릭하면 대응하는 구조물 목록, 신호 현시 목록 또는 소리 정의로 이동할 수 있습니다.
- 편집 모드에서 편집 가능한 요소의 셀을 오른쪽 클릭하면 `속성/편집` 또는 `삭제`를 선택할 수 있습니다. 일부 표는 셀을 두 번 클릭해 `속성/편집`을 엽니다.

#### 역과 구조물

- **역 목록** 위쪽의 역 정차 위치에는 `Station.Put` 거리, 출입문 방향 및 정차 위치 앞뒤 허용 범위가 표시됩니다. 상황에 맞는 메뉴의 `속성/편집`에서 바꿉니다. 아래쪽 역 정의에서 `Station.Load`로 불러온 역 이름, 도착·출발 시각, 정차 시간과 소리를 표에서 직접 편집합니다.
- **맵 구조물 목록**에 `Structure.Put`과 `Structure.Put0`이 표시됩니다. 평면도, 3D 장면 또는 모델 정의에서 항목을 찾을 수 있습니다.
- **맵 구조물 목록 (PutBetween)**에 두 궤도 사이에서 변형된 `Structure.PutBetween` 구조물이 표시됩니다.
- **구조물 목록**에 structureKey와 모델 경로가 표시됩니다. 키를 오른쪽 클릭하여 모델을 미리 보거나, 유형이 일치하는 열린 맵 요소 만들기 마법사에 키를 입력할 수 있습니다.
- **반복 구조물 목록**은 키가 같은 `Repeater.Begin`/`Begin0`/`End` 구문을 구간으로 묶습니다. 시작, 종료, 변경점으로 이동할 수 있습니다. `속성/편집`에서 구간 매개변수, 모델 순서와 종료 거리를 조정합니다. 자세한 내용은 10절을 참조하세요.
- **타 열차 목록**에는 타 열차 정의, 정차 지점, 읽기 전용 `Train.Enable` 시각이 표시됩니다. 경로를 개별적으로 표시하고 평면도에서 정차 지점을 찾을 수 있습니다.

#### 궤도 선형, 신호, 폐색 구간

- **다른 궤도**에서 `표시` 또는 `모두 선택`으로 2D와 3D의 궤도 표시를 바꿉니다. 시작·끝 거리와 색상은 2D 보기에 적용됩니다. 편집 모드에서 `키`를 오른쪽 클릭하여 해당 `Track[...]` 구문의 이름을 바꿀 수 있습니다. Structure, Signal, Repeater 구문의 궤도 참조는 별도로 편집합니다.
- **궤도 틀림 목록**, **점착 특성 변경점 목록**, **속도 제한 지점 목록**에 해당 위치를 표시하고 2D 또는 3D에서 찾을 수 있습니다. 속도 제한 Begin과 End는 독립적으로 둘 수 있습니다. End는 거리만 편집합니다.
- **신호 현시 목록**에는 신호 현시 정의와 구조물 키가 표시됩니다. 구조물 키에서 모델로 이동할 수 있습니다.
- **지상 신호기 목록**에는 `Signal.Put` 위치와 매개변수가 표시됩니다. 행마다 `표시`로 평면도 마커를 제어합니다.
- **폐색 구간 목록**에는 `Section.Begin`/`BeginNew`의 신호 인덱스와 `Section.SetSpeedLimit`/`Signal.SpeedLimit`의 현시별 제한 속도가 표시됩니다. `속성/편집`에서 `+`, `-`, 위아래 화살표로 매개변수를 추가·삭제·재정렬합니다. 현시별 제한 속도에서 `null`은 제한 없음을 뜻합니다. 한 행에 최대 508개 매개변수가 표시됩니다. 전체는 `속성/편집`에서 확인합니다.
- **지상자 목록**에 `Beacon.Put` 구문을 표시하고 해당 위치를 찾을 수 있습니다.
- **변수 목록**은 대소문자를 구분하지 않고 변수 이름별로 대입을 모읍니다. 마우스를 올리면 원래 식을 확인할 수 있습니다. 이 표는 읽기 전용입니다.

#### 소리와 효과

- **소리 파일 목록**과 **3D 소리 파일 목록**에는 소리 키, 파일 경로, 버퍼 수가 표시됩니다. 파일의 폴더를 열거나 유형이 일치하는 맵 요소 만들기 마법사에 키를 입력할 수 있습니다.
- **소리 재생 지점 목록**, **고정 음원 목록**, **주행음 변경점 목록**, **플랜지 소음 변경점 목록**, **이음매 소음 재생 지점 목록**에서 재생 또는 변경 위치를 확인하고 찾을 수 있습니다.
- **배경 변경점 목록**, **운전실 조도 변경점 목록**, **안개 변경점 목록**, **구형 안개 변경점 목록**, **풍경 표시 거리 변경점 목록**에서 해당 효과를 확인하고 위치를 찾을 수 있습니다.
- **광원**에는 `Light.Ambient` 및 `Light.Diffuse`의 RGB 값과 `Light.Direction`의 피치·요가 표시됩니다. 편집 모드에서 매개변수를 바꾸고 이 창의 `적용`, 도구 모음의 `저장`을 차례대로 누릅니다. 빠진 항목은 `새로 만들기`로 추가하고 기존 항목은 `삭제`로 지웁니다.
- **시나리오 파일**에는 열린 시나리오의 필드와 후보가 표시됩니다. 편집과 저장은 2절을 참조하세요.

#### 리소스 목록에서 직접 편집

편집 모드에서는 역 정의, 구조물 목록, 신호 현시 목록, 소리 파일 목록 및 3D 소리 파일 목록을 표에서 직접 편집할 수 있습니다.

- 편집 가능한 셀을 두 번 클릭해 입력합니다. `Enter`를 누르거나 셀 밖으로 이동하면 초안에 반영됩니다. 오른쪽 클릭으로 위아래에 행을 삽입하거나 행 전체를 위아래로 이동하고, 셀을 비우거나 행을 삭제합니다. 리소스 파일 경로 셀에서는 `파일 선택`도 사용할 수 있습니다.
- `행 추가`로 빈 목록에 첫 항목을 추가합니다.
- `파일 선택`은 가능한 경우 상대 경로를 저장하며, 그 외에는 절대 경로를 저장합니다.
- 신호 현시의 기본 행과 눈부심 행은 한 묶음으로 이동하거나 삭제합니다. 새 기본 행은 6개 필드로 시작합니다. `눈부심 행 추가`로 눈부심 행을 만듭니다.
- 표의 `적용`으로 메모리 미리 보기를 갱신합니다. 모든 표 초안을 적용한 뒤 도구 모음에서 `저장`을 눌러 파일에 씁니다.

신호 현시 목록은 오른쪽 끝의 빈 필드를 포함해 CSV 행의 실제 필드 수를 사용합니다. 그 행에 없는 필드는 대각선으로 표시됩니다. 기존의 빈 필드는 편집할 수 있습니다. 구조물 키는 최대 509열을 표시합니다. 초안과 원본에 유지되는 초과 필드는 안내 문구로 알립니다.

- CSV 셀을 오른쪽 클릭하여 오른쪽에 셀을 붙이거나, 오른쪽 끝의 빈 셀을 지우거나, 행의 마지막 셀을 삭제합니다. 기본 행과 눈부심 행의 필드 수는 서로 다를 수 있습니다.
- `모든 열 맞추기`는 행마다 최대 필드 수에 맞춰 빈 셀을 채웁니다. `오른쪽에 열 추가`와 `맨 오른쪽 열 삭제`는 행마다 셀 하나를 추가하거나 지웁니다. `오른쪽 끝의 빈 셀 모두 삭제`는 모든 행의 끝에 연속된 빈 셀을 지웁니다.
- 각 행은 첫 CSV 필드와 구조물 키 필드 하나 이상을 유지합니다. 구조물 키 필드는 비워 둘 수 있습니다. 눈부심 행의 첫 필드는 빈 값으로 고정되며, 행을 제거할 때는 `눈부심 행 삭제`를 사용합니다.
- 값이 있는 마지막 셀을 지우려면 확인이 필요합니다. 여러 열을 한꺼번에 조작할 때는 표시 한도를 넘는 필드도 포함합니다.

연속된 기존 눈부심 행은 하나의 행으로 합쳐 표시합니다. 편집할 때 합친 필드 수를 유지합니다. 이동 또는 `눈부심 행 삭제`는 눈부심 행 묶음 전체에 적용됩니다. 셀이나 열을 조작한 뒤 `적용`, `저장`을 누릅니다.

맵은 유형별로 리소스 목록 하나를 불러올 수 있습니다. 빠진 목록을 넣으려면 표에서 `파일 만들기 또는 가져오기`를 누릅니다. 교체하려면 위쪽의 `원본 경로`를 오른쪽 클릭하고 `파일 바꾸기...`를 선택합니다. 해당 목록에 적용하거나 저장하지 않은 변경이 있으면 폐기 전에 확인합니다.

Station List 0.04 이상, Structure List 1.00 이상, Signal Aspects List 및 Sound List 2.00 이상을 지원합니다. 일반 소리와 3D 소리는 같은 Sound List 형식을 사용합니다. 리소스 목록의 표준 주석 문자는 `#`이며, komapedit는 CSV 큰따옴표 바깥의 `//` 주석도 읽습니다.

### 7. 파일 구조도와 텍스트 미리 보기

`보조 정보 → 기타 → 파일 구조도`에서 창을 엽니다. 왼쪽에 시작 맵, 오른쪽에 Include 하위 맵이 깊이별로 표시됩니다. 노드에 마우스를 올리면 Include 인수와 절대 경로를 확인할 수 있습니다.

#### 파일 보기

- 유효한 노드를 오른쪽 클릭하고 `텍스트 미리 보기`를 선택하면 읽기 전용 창에서 원본과 줄 번호를 볼 수 있습니다.
- `속성/편집`의 원본 파일 이름에서도 `텍스트 미리 보기`를 열 수 있습니다. 맵과 리소스 목록의 텍스트 미리 보기는 `적용`할 때 갱신되므로 저장 전에 결과를 확인할 수 있습니다.
- `파일 탐색기에서 열기`로 해당 폴더를 엽니다. 폴더가 없으면 콘솔에 표시합니다.
- 없거나 유효하지 않은 Include 대상은 빨간색으로 표시합니다. 해당 노드에서는 텍스트 미리 보기, 하위 맵 가져오기, 새 하위 맵 기능이 비활성화됩니다.

#### Include 편집

편집 모드에서 다음 작업을 할 수 있습니다.

- `Include 파일 바꾸기...`는 새 `.txt` 또는 `.csv` 하위 맵을 선택하고 상위 파일의 Include 경로를 바꿉니다. 가능한 경우 상대 경로를 사용하고, 그 외에는 절대 경로를 사용합니다.
- `Include 연결 해제`는 상위 파일에서 Include 구문을 지웁니다. 뒤의 구문이 그 하위 맵의 데이터에 의존하면 연결 해제가 차단됩니다.
- `하위 맵 가져오기...`는 기존 BVE 맵을 선택하고 현재 노드가 나타내는 파일에 추가할 Include를 준비합니다.
- `새 하위 맵...`은 새 경로에 `BveTs Map 2.02:utf-8` 헤더, BOM 없는 UTF-8, CRLF 줄바꿈으로 빈 하위 맵을 만들고 Include를 준비합니다.

새 Include는 파일 자체의 첫 거리 구문 앞에 있는 마지막 Include 다음에 추가됩니다. 앞선 Include가 없으면 첫 거리 구문 앞에, 둘 다 없으면 파일 끝에 추가됩니다. 변경은 미리 보기에 바로 반영되며 `저장`하면 상위 맵에 기록됩니다.

komapedit에서 각 맵 파일의 `distance`는 `0`에서 시작합니다. Include에서 돌아오면 상위 파일의 거리를 복원하며 일반 `$variables`는 공유합니다. 하위 맵을 상위 맵의 위치에 맞추려면 Include 앞에서 `$dis=distance;`를 대입하고 하위 맵에서 `$dis+offset;`으로 거리를 지정합니다.

### 8. 3D 모델 미리 보기

`3D 보기 → 구조물 모델 미리 보기`를 연 뒤 다음 방법으로 모델을 엽니다.

- 도구 모음의 `파일 열기`로 모델 파일을 선택합니다. 구조물 목록에 없는 `.x` 파일도 열 수 있습니다. 대화 상자는 미리 보는 파일의 폴더에서 시작합니다. 모델을 아직 열지 않았다면 맵의 폴더에서 시작합니다.
- 구조물 목록에서 structureKey를 오른쪽 클릭하고 `모델 미리 보기`를 선택합니다.

도구 모음에서 다음 작업을 할 수 있습니다.

- `구조물 목록`으로 구조물 목록을 엽니다.
- `파일 열기`로 구조물 목록에 등록되지 않은 모델도 직접 선택합니다.
- `다시 불러오기`로 현재 모델, 재질, 텍스처를 다시 읽습니다.
- `비우기`로 미리 보기에서 현재 모델을 제거합니다.
- `배경색`으로 RGB 색을 고르거나 흰색, 검은색, 회색, 파란색, 초록색을 바로 선택합니다.
- 마우스 왼쪽 버튼으로 끌어 모델을 회전하고 휠로 확대·축소합니다.

모델이나 텍스처 불러오기에 실패하면 콘솔의 세부 내용을 확인하세요.

### 9. 3D 장면 미리 보기

`3D 보기 → 3D 장면 미리 보기`에서 `3D 장면 미리 보기 시작`을 누릅니다. 맵을 열거나 다시 불러올 때 자동으로 시작하려면 `옵션 → 3D 캔버스 설정`의 `맵을 열 때 장면 미리 보기 자동으로 불러오기`를 켭니다. 기본값은 꺼짐입니다.

창 위쪽에 `3D 장면 미리 보기 시작`, `모델 다시 불러오기`, `닫기`가 있습니다.

- `모델 다시 불러오기`는 현재 맵과 카메라 위치를 유지하며 장면의 모델을 다시 읽습니다.
- `닫기`는 현재 장면의 리소스를 해제합니다. 미리 보기 창은 열린 상태로 둘 수 있습니다.

#### 이동 모드와 단축키

포인터를 3D 캔버스에 두고 다음과 같이 조작합니다.

키보드 이동은 `이동`, `선택`, `거리 선택` 모드에서 쓸 수 있습니다. 마우스 왼쪽 버튼을 누른 채 끌어서 시점을 돌리는 조작은 `이동` 모드에서 쓸 수 있습니다.

| 조작 | 기능 |
| --- | --- |
| 마우스 왼쪽 버튼으로 끌기 | `이동` 모드에서 시점 회전 |
| `W` / `S` | 노선을 따라 앞뒤로 이동 |
| `A` / `D` | 좌우로 이동 |
| `R` / `F` | 위아래로 이동 |
| `Ctrl`을 누른 상태 | 위 이동 키로 빠르게 이동 |
| `X` | 현재 거리에서 기준 궤도 중심 위의 기본 카메라 자세로 복원 |

`3D 캔버스 설정`에서 카메라 속도를 조정합니다. 도구 모음에서 역 또는 거리로 이동할 수 있습니다. 카메라는 기준 궤도의 시작 지점 뒤로 최대 100 m까지 이동할 수 있습니다. `평면도에 현재 위치 표시`를 켜면 2D 평면도에 카메라 위치가 표시됩니다.

#### 선택 모드

- 장면 객체나 마커에 포인터를 올리면 강조 표시됩니다.
- 객체나 마커를 오른쪽 클릭하여 대응하는 맵 정보 표에서 찾습니다. 반복 구조물은 시작 또는 종료/변경 위치로도 이동할 수 있습니다.
- 신호기를 오른쪽 클릭하고 `신호 현시 전환`을 선택해 현시 인덱스와 구조물 키에 해당하는 모델로 바꿉니다.
- 편집 모드에서는 같은 메뉴에 `속성/편집`과 삭제 작업도 표시됩니다. 편집 기즈모는 10절을 참조하세요.

#### 거리 선택 모드

- 포인터 근처에 기준 궤도 평면의 가장 가까운 1 m 단위 단면과 거리가 표시됩니다.
- 편집 모드에서 이 위치를 오른쪽 클릭하고 `현재 거리에 맵 요소 추가`를 선택합니다. 마법사가 `distance`를 자동으로 채웁니다.

#### 장면 정보 표시와 설정

캔버스에는 카메라 위치, 현재 곡선 반경과 캔트, 구배, 제한 속도, 폐색 구간 신호 속도, 다음 역 정보가 표시됩니다. `Curve.Interpolate` 구간에서는 양 끝점의 반경, 캔트와 곡선 방향을 표시합니다. 두 반경이 모두 0이면 `직선`으로 표시합니다. 아래에는 장면 청크, 인스턴스, 불러온 모델, 프레임률이 표시됩니다.

FPS는 장면 캔버스의 갱신률입니다. 대기 중에는 마지막 값을 유지합니다.

`옵션 → 3D 캔버스 설정`에서 다음을 조정합니다.

- `표시 거리`는 카메라 전방의 장면 범위를 정합니다. `맵 구문에 따라 표시 거리 조정`을 켜면 `DrawDistance.Change`도 범위를 제한합니다.
- `안개 효과`는 맵 안개의 미리 보기를 켜거나 끕니다.
- `편집 도구 크기`와 `카메라 이동 속도`는 기즈모 크기와 키보드 이동 속도를 조정합니다.
- `성능 경고`는 그리는 인스턴스 수가 `경고 기준`을 넘으면 노란색, `심각 경고 기준`을 넘으면 빨간색으로 표시합니다.

관련 마커는 `보조 정보`의 표시 상태와 동기화됩니다.

안개 미리 보기는 지수 안개 `Fog.Interpolate`/`Fog.Set`과 선형 안개 호환 구문 `Legacy.Fog`를 지원합니다. 같은 종류의 지점 사이는 보간하고, 종류가 다르면 뒤 지점에서 전환합니다. `Legacy.Fog`의 시작과 끝 값은 카메라 깊이 방향 거리(m)이며 RGB는 0–255 범위입니다. 거리 0의 설정은 바로 적용됩니다. 뒤의 설정은 양쪽 모두 선형 안개일 때 25 m에 걸쳐 전환합니다. 두 안개 유형 모두 해당 표나 마커에서 편집하고 마법사의 효과 범주에서 만들 수 있습니다.

#### 장면 표지

`보조 정보`로 표지의 표시 여부를 제어합니다. `곡선 반경`이 켜져 있으면 `Curve.Interpolate` 지점의 반경, 캔트, 곡선 방향을 표시합니다. 반경이 0이면 `Intpl. 0`으로 표시합니다. 표지를 선택하고 강조할 수 있으며 편집 모드에서 오른쪽 클릭으로 편집하거나 삭제할 수 있습니다.

### 10. 편집, 생성, 저장

#### 편집 시작

도구 모음의 `편집 모드`를 처음 켜면 확인 창이 표시됩니다. `다시 표시하지 않기`를 선택하고 확인할 수 있습니다.

편집 모드를 켠 뒤에는 편집 데이터를 모두 불러올 때까지 기다립니다. `속성/편집`, 광원 표, 마법사에서 값을 입력한 뒤 창을 떠나기 전에 `적용`을 누릅니다. 대기 중인 변경이 있는 상태에서 편집 모드를 끄거나, 다른 문서를 열거나, 다시 불러오거나, 종료하면 변경 처리 방법을 묻습니다.

#### 초안, 적용, 저장, 되돌리기

맵과 리소스 목록은 다음 순서로 편집합니다.

1. **초안 편집**은 `속성/편집`, 리소스 목록 표 또는 마법사에서 값을 입력하는 단계입니다. 일부 객체는 입력 중에 미리 볼 수 있습니다.
2. **미리 보기에 적용**하려면 창의 `적용`을 누릅니다. 메모리 작업 사본을 검증하고 다시 파싱한 뒤 2D 보기, 표, 3D 미리 보기를 갱신합니다.
3. **디스크에 저장**하려면 도구 모음의 `저장` 또는 `Ctrl+Shift+S`를 사용합니다. 적용한 변경이 해당 맵, Include 또는 리소스 목록 파일에 기록됩니다.

저장 전에 모든 리소스 목록과 사용자 지정 메시지 초안을 적용합니다. 시나리오 입력란의 변경은 도구 모음의 `저장`으로 바로 기록합니다. 도구 모음의 `되돌리기`는 마지막 저장 시점의 메모리 상태로 복원합니다. 외부 편집기에서 저장한 변경은 `다시 불러오기`로 읽습니다.

프로그램은 저장 전에 편집 결과를 다시 파싱하고 검증합니다. 원래 인코딩, BOM, 줄바꿈을 보존합니다. 새 텍스트를 원래 인코딩으로 표현할 수 없거나 다른 프로그램이 파일을 바꾸었으면 저장을 중지하고 이유를 표시합니다.

#### 기존 맵 요소 편집 또는 삭제

1. 표의 항목 또는 2D/3D 마커를 오른쪽 클릭하고 `속성/편집`을 선택합니다.
2. 창에서 원본 파일, 원본 위치, 원본 구문을 확인하고 필드를 바꿉니다.
3. `적용`을 눌러 메모리 미리 보기를 갱신합니다.
4. 2D 보기, 표, 3D 결과를 확인합니다. 올바르면 도구 모음에서 `저장`을 누릅니다.

역, 구조물, 신호기, 지상자, 반복 구조물, 폐색 구간, 제한 속도, 곡선과 구배, 다른 궤도, 궤도 틀림, 소리, 배경, 점착 특성, 운전실 조도, 안개, 조명 매개변수, 표시 거리, 선행 열차 통과 지점을 편집할 수 있습니다. 상황에 맞는 메뉴에서 `삭제`를 선택하면 미리 보기에 반영되며, 저장하면 원본 파일에 기록됩니다.

`좌표 오프셋 추가` 또는 `좌표 오프셋 제거`로 `Structure.Put`/`Put0`이나 `Repeater.Begin`/`Begin0`을 변환합니다. 0이 아닌 오프셋을 제거할 때는 확인이 필요합니다. 짧은 `Signal.Put`의 Z, 회전, tilt 또는 span을 편집할 때는 전체 형식으로 변환할지 확인합니다.

#### 반복 구조물 구간 편집

- 반복 구조물의 `속성/편집`에서 `이전`과 `다음`을 눌러 키가 같은 구간 사이를 이동합니다.
- 구조물 키 목록 옆의 `+`, `-`, 위아래 화살표로 반복 배치할 모델을 추가·삭제·재정렬합니다.
- `변경점 삽입`은 현재 매개변수가 채워진 마법사를 엽니다. 새 거리와 매개변수를 입력하고 적용합니다. 마지막 구간에 End가 없으면 `종료 위치 추가`로 넣을 수 있습니다.
- 여러 구간으로 이어진 배치의 삭제 메뉴에는 `모두 삭제`, `변경점 삭제`, `변경점에서 끝내기`, `변경점에서 시작하기`가 있습니다. 각각 전체 연결 구문, 변경점 하나, 뒤쪽 구간, 앞쪽 구간을 제거합니다. 미리 보기를 확인한 뒤 저장합니다.

#### 3D 장면에서 실시간 조정

`속성/편집`을 열고 지원되는 객체의 기즈모를 끌어 초안을 조정합니다. 위와 같이 적용하고 저장합니다.

- `Structure.Put`, 전체 형식의 `Signal.Put` 및 `Repeater.Begin`은 X/Y/Z축으로 좌표를 조정합니다.
- `Sound3D[soundKey].Put(x, y)`는 X/Y축으로 상대 위치를 0.001 m 단위로, Z축으로 거리를 1 m 단위로 조정합니다.
- `Structure.Put0` 및 `Repeater.Begin0`은 Z축으로 거리를 1 m 단위로 조정합니다. 좌표 오프셋을 추가하면 전체 좌표 기즈모를 사용할 수 있습니다.
- 명시적 End가 있는 반복 구조물은 종료 위치의 Z축으로 종료 거리를 1 m 단위로 조정합니다.
- `Structure.PutBetween`은 Z축으로 거리를 1 m 단위로 바꾸고 변형된 모델을 실시간으로 다시 계산합니다.

#### 맵 요소 만들기 마법사

도구 모음에서 `맵 요소 추가`를 누르거나, 3D의 `거리 선택` 모드에서 현재 거리를 오른쪽 클릭합니다. 대상 원본 파일과 템플릿을 고르고 매개변수를 입력합니다. 불러온 맵 원본 파일은 빈 파일이거나 거리 구문이 없어도 대상으로 선택할 수 있습니다.

요소를 만들거나 이동할 때 프로그램은 다른 구문과 주석을 보존하며 거리 구문을 자동으로 배치합니다. 위치를 직접 지정해야 하면 텍스트 미리 보기에서 강조된 구문 경계를 선택하고 `확인`을 누릅니다. 거리 식이 필요하면 입력 창에 원본 식을 넣고 `적용`을 누릅니다.

마법사에서 지원하는 요소는 다음 범주로 나뉩니다.

- **구조물**은 `Structure.Put`, `Put0`, `PutBetween`, `Repeater.Begin`/`Begin0`/`End`를 제공합니다.
- **역**은 `Station.Put`을 제공합니다.
- **궤도 선형**은 곡선, 구배, 궤간, 캔트 회전 중심, 보간 함수, 궤도 틀림, 점착 특성 변경을 제공합니다.
- **다른 궤도**는 위치, X/Y 보간, 캔트의 `Track.*` 구문을 제공합니다.
- **신호**는 신호기, 제한 속도, 폐색 구간, 신호 속도, 지상자, `PreTrain.Pass` 지점을 제공합니다.
- **소리**는 맵 소리, 3D 음원, 주행음, 플랜지 소음, 이음매 소음을 제공합니다.
- **효과**는 배경, 운전실 조도, 안개, 조명 매개변수, 표시 거리를 제공합니다.
- **기타**는 맵 파일 헤더 아래에 주석으로 저장하는 사용자 지정 메시지를 제공합니다.

`적용`은 요소를 만들고 미리 보기를 갱신합니다. `적용 후 편집`은 마법사까지 닫고 새 요소의 `속성/편집` 또는 사용자 지정 메시지 탭을 엽니다. 반복 구조물 변경점 마법사에서는 `적용`을 사용합니다.

템플릿별 입력 방법입니다.

- **반복 구조물**의 Begin, End 또는 두 구문을 추가합니다. 쌍으로 추가할 때 종료 거리는 시작 거리 이상이며, 같은 키의 쌍으로 닫힌 구간은 서로 겹칠 수 없습니다. 구간 안의 매개변수 변경은 `변경점 삽입`으로 만듭니다.
- **곡선과 구배**의 시작, 끝 또는 둘 다 추가합니다. 곡선은 `Curve.Begin` 또는 `Curve.Change`로 시작해 `Curve.End`로 끝납니다. 구배는 `Gradient.Begin`/`End`를 사용합니다. Begin/End에 해당하는 완화 구간의 시작점도 넣을 수 있습니다. `Curve.Change`는 반경을 바로 바꿉니다.
- **곡선 보간점** `Curve.Interpolate`에는 거리가 필요합니다. 반경과 캔트의 기본값은 `0`입니다. 인수 하나를 쓰려면 캔트를, 인수 없는 형식을 쓰려면 반경을 해제합니다.
- **다른 궤도**의 선택 인수는 앞에서부터 활성화합니다. 예를 들어 `radiusV` 전에 `radiusH`를 포함합니다. 새 trackKey를 입력하면 다른 궤도가 생깁니다. 숫자 키와 따옴표로 둘러싼 문자열 키는 구분됩니다.
- **선행 열차 통과 지점**의 `passTime`은 `hh:mm:ss` 또는 자정부터의 초 단위로 입력합니다. 입력란에 포인터를 올리면 형식 안내가 표시됩니다.
- **조명** 구문은 거리 `0`에서 생성합니다. RGB 값은 `0`에서 `1` 사이로 입력합니다. Include를 포함한 전체 맵에서 조명 구문 종류별 정의는 하나입니다.

#### 사용자 지정 메시지와 제작자 메시지

맵 요소 만들기 마법사에서 `기타 → 사용자 지정 메시지`를 선택한 뒤 맵 원본 파일과 한 줄 메시지를 입력합니다. 적용하고 저장하면 파일 헤더 아래 빈 줄 다음에 아래 주석을 쓰거나 기존 메시지 블록 뒤에 추가합니다.

```plaintext
BveTs Map 2.02

//--kme--message-from-creator:"content"
```

메시지는 일반 BVE `//` 주석으로 저장합니다. 공백, 따옴표, 역슬래시를 그대로 유지합니다. 빈 메시지를 사용할 수 있으며 내용은 NUL 문자가 없는 한 줄이어야 합니다.

맵이나 시나리오를 열면 루트 맵과 불러온 Include의 메시지가 표시됩니다. 메시지가 여러 개면 페이지를 넘겨 볼 수 있습니다. 같은 파일을 여러 번 참조해도 메시지는 각각 한 번만 표시됩니다. `다시 표시하지 않기`를 선택하고 확인하면 루트 맵별로 그 선택을 기억합니다.

언제든 `보조 정보 → 기타 → 사용자 지정 메시지`에서 원본 파일, 줄 번호, 내용을 확인할 수 있습니다. 검색어를 입력하고 `Enter`를 누르거나 `찾기`를 클릭하여 원본 파일 이름 또는 메시지 내용을 검색합니다. 위아래 화살표로 결과 사이를 이동합니다.

편집 모드에서 내용 셀을 두 번 클릭해 편집합니다. `Enter`를 누르거나 셀에서 벗어나면 초안에 반영됩니다. `Esc`는 현재 입력을 취소합니다. 셀의 상황에 맞는 메뉴에서 `행 전체 삭제`로 삭제할 항목을 지정합니다. 탭의 `적용`을 누른 뒤 도구 모음에서 `저장`을 누릅니다.

#### 새 파일 마법사

`파일 → 새로 만들기...`에서 맵, 시나리오, Structure List, Signal Aspects List, Sound List, Sound3D용 Sound List 또는 Station List를 만듭니다.

1. 파일 종류를 고르고 확장자 없이 파일 이름을 입력한 뒤 `.txt` 또는 `.csv`와 폴더를 선택합니다.
2. 리소스 목록은 `파일 가져오기`로 기존 `.txt` 또는 `.csv`의 이름, 폴더, 확장자를 채운 뒤 필요에 따라 바꿀 수 있습니다.
3. 시나리오는 원하는 필드를 채웁니다. 빈 필드는 생략합니다. `파일 선택`으로 `Route`, `Vehicle` 또는 `Image`의 상대 경로를 입력합니다.
4. 맵을 불러온 상태에서 맵이나 리소스 목록을 만들려면 편집 모드를 켜고 `참조를 추가할 파일`에서 대상 원본 파일을 확인합니다. 열린 맵이 없으면 독립 파일을 바로 만들 수 있습니다.
5. `확인`을 눌러 파일을 만들거나 기존 파일을 사용합니다. 하위 맵을 만든 뒤 열기 전에 상위 맵에서 참조를 저장합니다. 독립 맵과 시나리오는 `확인 후 불러오기`도 제공합니다.

기존 일반 파일은 그대로 사용합니다. 새 파일은 UTF-8과 CRLF로 작성합니다. 맵과 리소스 목록에는 표준 헤더를 쓰고, 시나리오에는 표준 필드 순서로 내용을 씁니다.

시나리오 템플릿은 `Title`, `Route`, `RouteTitle`, `Vehicle`, `VehicleTitle`, `Author`, `Image`, `Comment` 여덟 필드를 제공합니다. 경로 필드마다 경로 하나를 입력하며, 값에는 `#` 및 `;` 같은 주석 문자를 피합니다. 여러 경로 후보와 가중치는 불러온 뒤 시나리오 파일 탭에서 편집합니다.

마법사는 파일을 즉시 만듭니다. `include` 또는 해당 `*.Load` 참조는 맵 미리 보기에 적용되고 도구 모음의 `저장`에서 기록됩니다. 맵은 종류별로 리소스 목록 하나를 참조할 수 있습니다. 참조한 파일을 교체하려면 표 위쪽의 `원본 경로` 상황에 맞는 메뉴를 사용합니다.

## 부록: CSV 데이터 형식

### 기준 궤도 선형 CSV 내보내기

`파일 → CSV 내보내기...`로 현재 선형 표본을 내보냅니다. 파일 이름 형식은 다음과 같습니다.

```text
<output-folder-name>_owntrack.csv
```

CSV 헤더는 다음과 같습니다.

```csv
#distance,x,y,z,direction,radius,gradient,interpolate_func,cant,center,gauge
```

| 필드 | 설명 |
| --- | --- |
| distance | 맵의 절대 거리(m) |
| x | 구배를 투영한 기준 궤도 평면 X 좌표(m) |
| y | 구배를 투영한 기준 궤도 평면 Y 좌표(m) |
| z | 표고(m) |
| direction | 궤도 방향각(rad) |
| radius | 부호 있는 곡선 반경(m). 우곡선은 양수, 좌곡선은 음수, 직선은 0 |
| gradient | 구배(‰) |
| interpolate_func | 보간 유형. `0`은 사인 반파장 완화, `1`은 선형 완화 |
| cant | 캔트(m) |
| center | 캔트 회전 중심의 가로 좌표(m) |
| gauge | 궤간(m) |

### 다른 궤도의 선형 CSV 내보내기

다른 궤도는 각각 별도 CSV로 내보냅니다. 파일 이름 형식은 다음과 같습니다.

```text
<output-folder-name>_<trackKey>.csv
```

trackKey의 `\ / : * ? " < > |` 문자는 `_`로 바꿉니다. 빈 키에는 `root`를 사용합니다. 궤도별 출력 파일 이름은 서로 달라야 합니다.

CSV 헤더는 다음과 같습니다.

```csv
#distance,x,y,z,interpolate_func,cant,center,gauge
```

| 필드 | 설명 |
| --- | --- |
| distance | 맵의 절대 거리(m) |
| x | 투영한 기준 궤도를 기준으로 계산한 다른 궤도의 평면 X 좌표(m) |
| y | 투영한 기준 궤도를 기준으로 계산한 다른 궤도의 평면 Y 좌표(m) |
| z | 다른 궤도의 표고(m) |
| interpolate_func | 캔트 보간 유형. `0`은 사인 반파장 완화, `1`은 선형 완화 |
| cant | 캔트(m) |
| center | 캔트 회전 중심의 가로 좌표(m) |
| gauge | 궤간(m) |

내보낸 CSV에는 궤도 선형 데이터가 들어 있습니다. 수치는 소수점 아래 여섯 자리까지 표시합니다.
